2. 背景与目标

REQ-01 产品问题

企业需要在统一后台完成课程与课件的生产、发布、评论治理与学习激励规则配置，使员工端可见内容可控、可运营。

主用户
培训管理员 / 内容运营
主场景
维护分类 → 上传课件 → 组装课程 → 发布 → 审核评论 → 配置积分/学分规则 → 查看概览与学习记录
产品目标
提供完整、可验收的「课程」应用后台能力规格，使研发/AI 可按 INT/AC 复现或对齐实现。
成功定义
六大页面边界内交互均可按本文契约复现；发布态与评论态机与枚举一致；关键校验不可绕过。
Out of scope
C 端学习播放器细节、真实媒体转码、真实权限中台、题库题目 CRUD、消息推送通道实现。

4. 源码事实 / 产品决策 / 假设 / 未决

Confirmed source facts

  • 应用菜单：概览、课程管理、课件管理、规则设置（navigation.ts）。
  • 课程状态：草稿 / 已发布 / 已下架；已发布不可删，须先下架。
  • 课件发布：草稿 / 已发布；仅草稿可删。
  • 评论：审核开启时新评论进 待审核；否则直接 已通过。
  • 驳回原因：选填（全局驳回交互约定）；通过/驳回有确认流。
  • 分类树最深 3 级；同级名不可重；有内容不可删。
  • 课程表单目录至少 1 个课件；名称 ≤20。

Confirmed product decisions（本次自行拍板）

  • 本文档目标是完整基线规格，Change type 以 Unchanged 为主（记录应保持的行为）。
  • 交付物以单 HTML 为主；标注图以内嵌 SVG 线连编号圈交付（Mode D 仍保留标注义务）。
  • 不改动任何既有 `docs/prd/**` 文件。

Assumptions

  • 管理员具备「课程」应用全部菜单权限。
  • 原型演示数据足以覆盖三种课程类型与评论三态。
  • 若错：真实权限系统需另补 RBAC 表，不影响本基线字段与状态机。

Unresolved decisions

  • 真实对象存储与转码策略（非本原型范围）。
  • 学习记录「详情」目前仅为提示，完整学员轨迹页未定义。

5. UI 设计方向

  • 遵循项目既有 B 端规范：Ant Design、列表四层（筛选 / 工具栏 / 批量栏 / 表）、横向表单标签固定宽。
  • 主操作在左（新增、保存、批量通过等）；危险操作确认 Modal。
  • 空态文案使用页面内既有中文（如「没有符合条件的课程」「暂无待审核评论」）。
  • 不引入新视觉主题；无新组件模式。

11. 验收标准

AC-01-01 Given 存在课程与待审评论 When 打开概览 Then KPI 与待审表可见，未发布计数仅含草稿
AC-01-02 Given 待审评论 When 点击通过并确认 Then 状态变已通过且 message 成功
AC-01-03 Given 待审评论 When 驳回（原因可空） Then 状态变已驳回

AC-02-01 Given 课程列表 When 按名称+状态+分类+类型 Tab 组合筛选 Then 仅展示匹配行，无匹配显示空态
AC-02-02 Given 草稿或已下架课程 When 发布 Then 状态=已发布
AC-02-03 Given 已发布课程 When 撤销 Then 状态=已下架
AC-02-04 Given 已发布课程 When 尝试删除 Then 阻断并提示需先下架

AC-03-01 Given 缺封面或目录为空 When 保存 Then 校验失败不落库
AC-03-02 Given 合法表单 When 新建保存 Then 生成草稿课程并可在列表看到
AC-03-03 Given 编辑脏数据 When 取消/返回 Then 弹出离开确认

AC-04-01 Given 有效课程 id When 打开详情四 Tab Then 路由 tab 与内容一致
AC-04-02 Given 无效 id When 打开详情 Then 显示不存在并回列表
AC-04-03 Given 开启答题并配置合法题库 When 保存 Then 配置持久化

AC-05-01 Given 待审核 When 批量通过 Then 全部变已通过
AC-05-02 Given 已通过 When 尝试驳回 Then 操作不可用或无效
AC-05-03 Given 任意状态评论 When 删除 Then 记录移除

AC-06-01 Given 合法课件表单 When 保存 Then 草稿入库
AC-06-02 Given 草稿 When 发布 Then 状态=已发布且不可删
AC-06-03 Given 已发布 When 撤销 Then 回草稿且可删

AC-07-01 Given 开启发放但未填正整数 When 保存 Then 校验失败
AC-07-02 Given 日上限<课上限 When 保存 Then 校验失败

AC-08-01 Given 同级重名 When 新建分类 Then 失败提示
AC-08-02 Given 分类下有课程 When 删除 Then 阻断
