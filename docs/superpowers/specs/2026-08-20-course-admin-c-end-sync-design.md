# 课程 C 端 / 管理后台数据联动

**状态：** 已实现  
**日期：** 2026-08-20  
**范围：** 课程主数据、分类树、评论、点赞/收藏三端（后台 + H5 + PC）共用；评论独立 store；C 端分类树直接用后台课程分类树。

## 决策

| 项 | 选择 |
|---|---|
| 主数据源 | `trainingStore` 课程；C 端只展示 `已发布` |
| 分类 | C 端读 `useCourseCategoryTree()` |
| 评论 | `courseCommentStore`，按 courseId |
| 赞/藏 | `courseEngagementStore` |
| 适配 | `clientCourse.ts` 改为映射层，去掉独立课程种子列表依赖 |

## 行为摘要

- 后台改名/发布/下架 → 商城与详情即时变。
- 发评：审核关写入已通过；审核开写入待审核且 C 端列表不可见。
- 后台「查看评论」只读列表（可删）。
- commentConfig 继续控制入口显隐。

## 非目标

登录、回复树、审核工作流页、学习进度写回。
