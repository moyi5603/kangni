# 课程评论配置

**状态：** 已实现  
**日期：** 2026-08-20  
**范围：** 后台课程管理「评论配置」弹窗；配置写入 `CourseRecord`；H5/PC 课程详情按开关隐藏评论/点赞/收藏，并处理评论审核开关的发评行为。不做审核队列与「查看评论」页。

## 决策摘要

| 项 | 选择 |
|---|---|
| 入口 | 课程列表「更多 → 评论配置」 |
| 承载 | Modal（4 个开关，≤6 字段） |
| 数据 | `CourseRecord.commentConfig` |
| C 端 | 按课程 id 读配置；无后台课程时默认全开（审核默认关） |
| 底栏 | 保存左 / 取消右 |
| 审核 | 开启后发评 toast「已提交，待审核」，不写入可见列表 |

## 字段与文案

| key | 标题 | 说明 | 默认 |
|---|---|---|---|
| commentEnabled | 评论 | 允许用户发表评论 | true |
| commentAuditEnabled | 评论审核 | 评论是否需要审核（仅对当前设置后产生的数据生效） | false |
| likeEnabled | 点赞 | 允许用户点赞 | true |
| favoriteEnabled | 收藏 | 允许用户收藏 | true |

## 文件

- `training.ts` / mock：类型 + 默认 + VERSION++
- `CourseListPage.tsx`：弹窗
- `H5CourseDetail.tsx` / `PcCourseDetail.tsx`：读配置并联动
- 对应测试更新

## 非目标

查看评论、审核列表、列表卡赞藏评数字、真发评写库（审核关时仍可为本地 demo 追加或保持现有「待开发」——以详情现有行为为准：若当前发评为 toast 待开发，审核关时保持；审核开时改为「已提交，待审核」）。
