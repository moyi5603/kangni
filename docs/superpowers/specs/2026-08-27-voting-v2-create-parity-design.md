# 投票版本2 创建页功能对齐

**日期：** 2026-08-27  
**参考：** [人人微投票创建活动](https://www.pingxuan520.com/create?id=jnO3mzB)  
**范围：** B 端壳内 **功能 1:1**（四步 + 左预览 + 保存后加选手）。微信实网能力（验证码网关、黑名单、强制关注）为开关模拟，不接腾讯。视觉用 Ant Design，不抄参考站皮肤像素。

## 布局

左手机样机预览，右四步页签：基本设置 / 样式设置 / 功能设置 / 高级功能。底栏：保存并发布、下一步、取消。新建保存后进入编辑页以便添加选手。

## 基本设置

活动名称、投票时间、活动介绍。

## 样式设置

封面方式（图片/视频/链接）、封面地址/上传、主题色（蓝青红橙黄绿紫粉）、漂浮物、背景音乐名、选手称谓、投票按钮称谓、选手列数、自定义底栏导航×2。

## 功能设置

自主报名（次数、审核、报名时间、报名字段显示）、分组（列数、组名）、票规（每天/总共、单选/多选、每人票数、同一选手）、防刷（验证码、微信黑名单、智能防刷、可投地区）、选手管理（保存后添加）。

## 高级功能

分享模式/标题/内容、关注后投票、广告、投票成功弹窗、底部版权、内部投票（邀请码生成）。
