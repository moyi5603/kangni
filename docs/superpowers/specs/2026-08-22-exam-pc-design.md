# 考试 PC 全流程

**状态：** 已定稿  
**日期：** 2026-08-22  
**范围：** C 端 PC 考试列表 → 准备 → 答题 → 结果 → 回顾，对齐 H5 业务逻辑与课程 PC 壳层风格。

## 决策

| 项 | 选择 |
|---|---|
| 路由 | `#/c/exam` 系列，对齐 `#/c/course` |
| 壳 | `PcActivityShell className="is-exam"` |
| 列表 | 仿 `PcCourseMall` 顶栏 + H5 考试 mall 侧栏分类 |

| 数据 | 复用 `clientExam*` / `clientExamSession` / `clientExamResult` |
| 已通过 | 「看成绩」跳结果页，不再 toast |
| 回顾 | 「回顾答题」跳回顾页，不再 toast |

## 路由

| Hash | 页 | 壳标题 |
|---|---|---|
| `#/c/exam` | 列表 | 考试 |
| `#/c/exam/:id` | 准备 | 考试准备 |
| `#/c/exam/:id/take` | 答题 | 考试中 |
| `#/c/exam/:id/result` | 结果 | 考试结果 |
| `#/c/exam/:id/review` | 回顾 | 考试回顾 |

`navigation` 增 `toPcExam*` / `goPcExam*`；`parseCEndHash` 识别 `surface === 'exam'`；`CEndApp` PC 分支挂 5 页；门户加「考试 PC」。

## 列表

- 搜索（提交才过滤）、L1 Tab、不看已结束（默认开）
- 有 L2 时左侧竖 Tab + 右侧 L3 横 Tab + 卡片列表
- 卡片：标题、总分、时长、开考/结束时间；已通过标 +「看成绩」
- 卡片点击 → 准备页

## 准备 / 结果 / 回顾

- 准备：2×2 指标、次数、规则、底栏「开始考试」
- 结果：双卡布局、明细行、「回顾答题」「考试记录」
- 回顾：上卡统计、「只看错题」、题卡列表、「返回结果页」

## 答题

- 左：题号网格（当前高亮、已答标记）
- 右：题型、题干、选项/问答、上一题 / 下一题 / 末题「立即交卷」
- 顶：倒计时；未答完交卷 toast

## 不做

真切屏检测、新 mock、改 B 端、改课程 PC。
