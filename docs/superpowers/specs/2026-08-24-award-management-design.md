## 状态

时间字段：征集开始 `collectStartAt`、提名截止 `nominateEndAt`、投票截止 `voteEndAt`。  
约束：征集开始 < 提名截止 < 投票截止。

相对 `now`：

| 条件 | 状态 |
|---|---|
| now < 征集开始 | 未开始 |
| 征集开始 ≤ now ≤ 提名截止 | 征集中 |
| 提名截止 < now ≤ 投票截止 | 投票中 |
| now > 投票截止 | 已结束 |

公示展示：

- 未结束：`-`
- 已结束：`未公示` / `已公示`
- 创建开关 `autoPublishOnEnd`：进入已结束且未手动改过时自动已公示
- 已结束后可手动公示 / 取消公示（锁定手动结果）

## 列表

结构：`ListPageHeading` → `SearchPanel` → `ListTableCard`（工具栏 / 批量栏 / 表）。

副标题：`查询并维护评优活动、名次奖励与公示。`

查询（顺序对齐列；>3 默认收起前三项）：评优名称、状态、类型；展开：提名截止日期、投票截止日期、公示。日期均为可空 RangePicker。

列：评优名称（链接详情）、状态、类型、提名截止日期、投票截止日期、提名（提交次数，数字）、待审提名（数字）、操作。数字右对齐。名称不截断除非规范另有要求——本轮名称允许 ellipsis。

工具栏主按钮：创建评优活动。

行操作：编辑；已结束显示公示或取消公示；未开始显示删除。超过展示数量收入「更多」。

批量：勾选后出现。仅未开始可删；已选含不可删则提示跳过。Footer 主左：确认删除 / 取消。

空：无数据用规范 `emptyText`；有筛选无结果单独文案「没有符合条件的评优活动」。

提名次数、待审提名：种子字段，本轮不进名单页。

## 新建 / 编辑表单

面包屑：`评优 > 评优管理 > 新建评优|编辑评优`。底栏固定：保存（左）取消（右）。未保存离开确认。

| 分组 | 字段 | 默认 | 组件 | 必填 / 校验 | 联动 |
|---|---|---|---|---|---|
| 基础 | 评优活动名称 | 空 | Input ≤50 | 必填 | 无 |
| 基础 | 评优类型 | 个人 | Radio 个人/团队/项目 | 必填 | 无 |
| 时间 | 征集开始 | 空 | DatePicker showTime | 必填 | 须早于提名截止 |
| 时间 | 提名截止 | 空 | DatePicker showTime | 必填 | 须晚于征集开始、早于投票截止 |
| 时间 | 投票截止 | 空 | DatePicker showTime | 必填 | 须晚于提名截止 |
| 内容 | 活动简介 | 空 | TextArea ≤500 | 必填 | 无 |
| 内容 | 评优标准 | 1 条空 | Form.List 最多 3 | 至少 1 条非空，最多 3 | 无 |
| 名次奖 | 前 x 名 | 3 | InputNumber 1–10 | 必填 | 变化时同步奖项行数 |
| 名次奖 | 每名：奖项名称 | 第 n 名 | Input | 必填 | 无 |
| 名次奖 | 每名：奖励勾选 | 积分 | Checkbox 积分/勋章/证书 | 至少一项 | 显示对应控件 |
| 名次奖 | 积分数值 | 空 | InputNumber ≥0 整数 | 勾选积分则必填 | 无 |
| 名次奖 | 勋章 | 空 | Select 活动勋章库 | 勾选勋章则必填 | 无 |
| 名次奖 | 电子证书 | 空 | Select 评优证书；可链到证书管理 | 勾选证书则必填 | 无 |
| 范围 | 可见范围 | 全员 | Radio 全员/按部门/自定义人员 | 必填 | 部门树或多选人员 |
| 范围 | 提名人 | 全员 | Radio 全员/指定部门/指定人员 | 必填 | 部门树或人员树 |
| 范围 | 提名范围 | 全员 | Radio 全员/所属部门内/指定部门范围 | 必填 | 指定部门时出部门树 |
| 公示 | 结束后自动公示 | 关 | Switch | 否 | 无 |

无全局奖励。编辑保留种子提名计数。

## 详情占位

展示名称、状态、类型、时间、提名/待审数字、简介摘要。文案：提名名单与审核后续补充。可返回列表、点编辑。

## 评优证书

列表：封面缩略图、证书名称、关联评优数、操作编辑/删除。工具栏：新建证书。弹窗字段：名称（必填）、上传图片（必填，本地 data URL）。Footer 确认在左。删除若被评优名次引用须提示关联。不与考试证书共用。

## 种子

至少覆盖四态 + 已结束公示/未公示各一条。当前演示时钟按页面加载时的系统时间计算状态。
