# H5 课程列表：最多三级分类

**状态：** 已批准（方案 A：L2 Tab + L3 按钮下方弹出）  
**日期：** 2026-08-19  
**范围：** 员工端 H5 课程列表的分类数据与筛选。不改管理端课程分类页、课件分类树、活动 H5。

## 背景

当前 H5 课程列表是两级硬编码：`category` + `subcategory`。一级胶囊，二级下划线 Tab。产品确认：分类最多三级，课程可挂任意节点。三行 Tab 会再吃约一行高度，小屏列表被挤。改为二级 Tab 槽位下钻到三级，高度与现稿两级相同。

## 决策摘要

| 项 | 选择 |
|---|---|
| 深度 | 最多 3 级，禁止第 4 级 |
| 挂载 | 课程 `categoryId` 可指向任意节点，不强制叶子 |
| 筛选 | 选中节点 N，列出 N 及其全部子孙上的课 |
| H5 形态 | L1 胶囊 + L2 Tab。有子级的 L2 在行尾出 `全部 ▾`，L3 在按钮下方右对齐弹出 |
| 有子级的二级 | Tab 行不换。点 ▾ 在按钮下方弹出 3 列网格 |
| 无子级 | 点了只筛选，无 ▾ |
| 数据源 | H5 独立演示树。本轮不接管理端课程分类 |
| 默认选中 | 一级「技能培训」，二级「全部」，无三级面板 |

## 数据

分类改为树，课程只存一个 `categoryId`。

```ts
type CourseCategoryNode = {
  id: number;
  name: string;
  children?: CourseCategoryNode[];
};

type ClientCourse = {
  id: number;
  title: string;
  categoryId: number;
  tag: string;
  views: number;
  duration: string;
  cover: ClientCourseCover;
};

type ClientCourseQuery = {
  keyword: string;
  categoryId: number | null;
};
```

深度：根到叶路径长度 ≤ 3。演示数据写死。

「全部」不是树节点。一级「全部」= `categoryId: null`。Tab 行上的「全部」= 当前槽位的父节点。

## 筛选语义

`filterClientCourses(list, tree, { keyword, categoryId })`：

1. `keyword` 非空：标题包含关键词。
2. `categoryId == null`：不过滤分类。
3. 否则：课程挂在 N 或 N 的子孙上。
4. `categoryId` 在树中不存在：该课只在一级「全部」出现。

H5 折算：

| L1 | L2 | L3 | 实际 N |
|---|---|---|---|
| 全部 | 隐藏 | 无 | `null` |
| 技能培训 | 全部 | 无 ▾ | 技能培训 |
| 产品岗 | 需求分析 | 面板「全部」 | 需求分析 |
| 产品岗 | 需求分析 | 面板「需求采集」 | 需求采集 |

切一级：二级、三级回到「全部」，关掉面板。一级「全部」：隐藏 Tab 行。

## H5 交互

搜索、卡片、底栏不变。分类区永远最多两行（胶囊 + Tab）。三级不进 Tab。

```
搜索
[全部] [技能培训] [产品岗] …
全部 | 需求分析 | 用户研究          全部 ▾
```

- 点「需求分析」（有子级）：L2 行不换，行尾出现 `全部 ▾`
- 点 ▾：按钮下方右对齐弹出 3 列网格，含「全部」和 6 个三级
- 选中三级后关面板，触发器显示当前三级名
- 点遮罩或再点 ▾：关闭面板
- 「用户研究」无子：无 ▾，点了直接筛
- 无子级的一级（公开课）：只有胶囊
- 切一级或二级：三级回到「全部」，关掉面板
- 空列表：「暂无课程」，筛选项保留
- 卡片 `tag` 仍用演示字段

## 演示树

```
全部
├─ 技能培训
│  └─ 初级会计考证
│     ├─ 入门
│     └─ 精通
├─ 产品岗
├─ 研发岗
└─ 人力
```

| 课 | 挂在 |
|---|---|
| 快速提升自己的沟通能力 | 技能培训（一级） |
| 产品技能培训2026-07-08 | 技能培训（一级） |
| 初级会计培训 | 初级会计考证（二级） |
| 会计入门精讲 | 入门（三级） |

默认「技能培训 + 未下钻全部」：四张都可见（含子孙「会计入门精讲」）。  
下钻到「初级会计考证」且 Tab「全部」：初级会计培训 + 会计入门精讲。  
选「入门」：仅会计入门精讲。  
选「产品岗」：产品需求分析实战；无 Tab。

其它岗位课仍挂各自一级。

## 架构

| 单元 | 职责 |
|---|---|
| `clientCourse.ts` | 树、课、查找、子孙 id、`l2Tabs`、`l3Options`、`resolveFilterId` |
| `H5CourseList.tsx` | L1 胶囊、L2 Tab、L3 触发器 |
| `H5CourseL3Sheet.tsx` | 按钮下方右对齐弹出的 3 列网格 |
| `H5CourseCards.tsx` | 卡片。不感知层级 |
| `styles.css` | Tab 行尾触发器 + L3 网格。不加第三行 Tab |

`H5CourseList` 不遍历子孙。当前槽位折成 `categoryId` 后交给 `filterClientCourses`。

## 异常

- 某级只有一个子节点：仍显示「全部」+ 该子节点，不自动跳过、不自动下钻。
- 关键词与分类同时生效。

## 测试

- 选父节点含直接挂载课和子孙课。
- 选具体三级只含该节点。
- 一级「全部」/ 无子一级：`buildSubTabs` 不可见。
- 点有子级的二级：`showBack` 为真，Tab 换成该二级的子。
- 点返回：回到一级的子 Tab，不再出现三级名。
- 演示树最大深度 = 3。
- 默认首屏能看到现稿三张课，以及「会计入门精讲」；首屏不出现「入门」「精通」Tab。

## 验收

- 任何时刻分类区不超过：搜索 + 胶囊 + 一行 Tab（行尾最多一个 ▾）。
- 一级无子：无 Tab。
- 二级有子：L2 行不换，行尾出 ▾；按钮下方弹出网格选三级。
- 二级无子：无 ▾。
- 挂在一级的课，L2「全部」可见；选某个二级后，只留该二级子孙。
- 路由仍是 `#/c/h5/courses`。

## 非目标

- 不改管理端「课程分类」平铺表。
- 不复用课件分类树，不打通 B 端 store。
- 不做第四级、不做三行 Tab、不做同槽下钻、不做级联选择器。
- 不做课程详情、学习进度。
- 不改活动 H5。
