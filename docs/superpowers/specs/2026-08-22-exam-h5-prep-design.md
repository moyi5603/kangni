## 准备页

- 壳标题「考试准备」，返回列表
- 考试名
- 2×2：总分 / 及格分 / 总题数 / 考试时长
- 考试次数：`总考试次数 N次，当前剩余 M次`，次数蓝色
- 考试规则：防切屏超 3 次自动交卷（含接电话）
- 底栏胶囊「开始考试」→ 答题页

## 数据

`getClientExamPrep(id)`：B 端考试 + C 端试卷题数；次数缺省 5，剩余=总次数（无已考记录）。
