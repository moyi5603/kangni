# 投票版本2 选项管理

**日期：** 2026-08-28  
**状态：** 待用户确认规格  
**规范：** `build-ant-design-b2b-app`（搜索列表 + 抽屉；视觉用 Ant Design，不抄参考站皮肤）  
**参考：** [人人微投票选手管理](https://www.pingxuan520.com/manage/player/jnO3mzB)  
**范围：** B 端独立 **选项管理** 页。搜标题/编号、分组筛、增删改复、批量改组/删、图片与 CSV 导入。无视频/音频、票数、锁定。微信实网、对象存储、C 端实投拦截不做。

覆盖既有创建页规格中「功能设置里嵌选手表 / 新建保存后停编辑页加选手」：选手改走独立页。

## 决策

| 项 | 选择 |

## 列表页结构

复用 `SearchPanel`、`ListPageHeading`、`ListTableCard`。内容区流式占满，不写死页宽。

### 查询

三项，默认全部展示，不提供展开。标签+控件同行。

| 顺序 | 字段 | 默认 | 数据源 | 控件 |
|---|---|---|---|---|
| 1 | 关键词 | 空 | 选手姓名、编号（`voteV2SampleNo`）包含匹配 | Input |
| 2 | 分组 | 全部 | 活动 `groups` +「未分组」（`groupId` 空） | Select |
| 3 | 锁定 | 全部 | 静态：全部 / 已锁 / 未锁 | Select |

按钮组占第四格：查询（Primary + SearchOutlined）→ 重置（ReloadOutlined）。无必填查询。条件变化回第 1 页并清空行选。筛选、排序、页码、每页条数写入 URL。

### 表格

行键：`id`。分页。空态区分：活动下无选手 / 筛选无结果。

列（左信息、右操作；一列一字段）：

1. 编号  
2. 封面（图；无图占位，不与姓名合并）  
3. 姓名（链接打开详情 Drawer）  
4. 分组（未分组显示「未分组」）  
5. 票数（右齐，单位用活动投票单位）  
6. 锁定（Tag：已锁 / 未锁）  
7. 操作（表头与单元格右对齐）

描述、视频、音频只在 Drawer。超长省略，Hover/聚焦 Tooltip。

工具栏左：共 N 条；有勾选时「已选择 M 项」，范围=当前页勾选，不跨页。  
工具栏右（危/次 → 主，仅「添加」为 Primary）：批量删除 → 批量改组 → 批量锁定 → 批量解锁 → 改票数 → 批量导入 → **添加{称谓}**。无勾选时批量禁用。

行内（仅实际动作）：详情 → 编辑 → 复制 → 锁定或解锁（互斥）→ 删除。超过可见上限进「更多」，删除最右危险色。无障碍名带对象，如「编辑 张工」。

## 行与批量行为

| 动作 | 行为 |
|---|---|
| 删除 / 批量删除 | Modal 确认：对象姓名或数量 +「删除后不可恢复」。成功 Message，清已成功勾选，保留页码 |
| 批量改组 | Modal：Select 目标分组或未分组，写回选中行 |
| 批量锁定 / 解锁 | 直接改 `locked`；高影响不二次确认（可逆）。已是目标状态的行算成功 |
| 改票数 | Modal：`InputNumber` ≥0，**设为该绝对值**（不是加减） |
| 复制 | 新 id；票数 0；未锁；其余字段拷贝；打开编辑 Drawer |
| 批量导入 | Modal，见下 |

部分失败：Message/Notification 写成功数、失败数与原因；失败行保持勾选。

### 批量导入

同一 Modal，两个 Tab。

**图片：** 多选本地图；去掉扩展名后的文件名 → 姓名；无姓名则该文件失败。默认未分组；Modal 内可选写入分组。票数 0、未锁。封面用本地预览 URL。

**表格：** 本地 CSV。列：编号、选项标题、副标题、分组、描述。不解析媒体列。

不接对象存储、不接微信。

## 抽屉（详情 / 编辑 / 新增）

同一 Drawer。详情只读；新增/编辑可写。桌面标签宽 112px、标签与控件同行。底栏右对齐：取消 → 保存。有未保存离开提醒。提交中禁用保存。校验失败滚到首个错误。

| 字段 | 必填 | 控件 | 默认 | 联动 |
|---|---|---|---|---|
| 姓名 | 是 | Input | 空 | 无 |
| 分组 | 否 | Select | 空=未分组 | 活动未开分组则隐藏 |
| 封面图 | 否 | Upload 图 | 空 | 本地预览 URL |
| 视频 | 否 | Upload 或 URL | 空 | 本地预览 URL |
| 音频 | 否 | Upload 或 URL | 空 | 本地预览 URL |
| 描述 | 否 | 富文本 + 右侧可选模板（同活动介绍模板库） | 空 | 保存保留 HTML，不 trim |
| 票数 | 是 | InputNumber ≥0 整数 | 0 | 无 |
| 锁定 | 否 | Switch | false | 无 |

详情 Drawer 底栏：关闭；标题区可「编辑」切到编辑态。编辑关闭后保留列表查询与分页。

## 数据

`VoteV2Contestant` 增加 `locked: boolean`，缺省 `false`。既有 mock（如车间安全之星选手）补 `locked: false`。

Store：在现有 `upsert`/`remove` 上补批量更新分组/锁定/票数、按文件名导入、复制。规则纯函数放 `voteV2.ts`，页面不写业务判断。

## 其它页面

- **投票列表：** 行操作增加「选手管理」链接 → `vote-v2-players`。行内顺序遵守规范：详情类链接在信息列或操作列靠前，删除仍最右。当前列表若无详情页，操作为：编辑 → 选手管理 → 删除。
- **创建/编辑页：** 删除选手 Table 与「添加选手」弹窗。已保存活动在功能设置「选手管理」只留说明 + 按钮「去选手管理」。未保存仍提示先保存发布。
- **手机预览：** 本轮不改 C 端路由；预览投票按钮对 `locked` 选手禁用即可，不做真实投票。

## 本轮不做

C 端选手详情/投票页、真上传云、微信验证、改 `b2b-standards.json`、跨页勾选、Excel 二进制（仅 CSV）。

## 测试与验收

- `navigation.test.ts`：`vote-v2-players` 解析、回落、sider 高亮列表。
- 列表页：查询三项、分页 URL、空态、增改复锁删、批量改组/锁/票/删、两种导入。
- 表单页：无选手表；已保存有「去选手管理」。
- Store/model：`locked` 默认、复制票数 0、导入文件名、CSV 缺姓名失败。

用户可观察：从列表进选手页能完成参考站同能力闭环；编辑页不再堆选手表。
