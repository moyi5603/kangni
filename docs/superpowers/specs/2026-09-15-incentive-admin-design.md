原型是「勋章、积分与认可」运营台：同事互认 + 公司表彰，积分跟勋章走，后台管规则、发放追溯、额度与风控。已在「全部应用」挂独立应用 `incentive`。本轮按规范把占位页换成可演示的四模块后台。

### Quota

组织或个人月度额度。组织额度单位是「积分/人」。月度总额度=人数×额度。已使用随所选统计月缩放（mock）。同一对象不可重复配置。

## 页面

### 数据总览（看板）

不是搜索列表。标题行右：统计周期 RangePicker（默认空=本自然月，起止均可空）+ 组织范围 TreeSelect + 查询/重置。单位管理员组织范围锁本单位。

KPI 四卡，每卡带「数据含义」Tooltip：

1. 员工参与率 = 周期内发过勋章去重人数 ÷ 范围内员工数  
2. 认可次数 = 已生效同事认可 + 公司表彰条数  
3. 累计发放积分 = 已生效积分合计  
4. 跨部门认可占比 = 发起人与对象二级部门不同的次数 ÷ 认可次数  

下方：勋章分布（类型筛选 + 分页条形）、勋章流向桑基（一/二级团队、发放/接收多选、勋章；未选不同团队则空态文案）、认可排行榜（对象员工/团队、关键词、勋章、完整导出 mock CSV）。参与度折线 30 点模拟，挂在 KPI 下或分布卡内。

点查询才刷新全页指标与图。

### 勋章管理

单位：整页空态，无树无表。

集团：面包屑+标题在上，左树+右列表。

左树：归属为一级、分类为二级。选中进 URL。归属/分类可新增、重命名、上下移、删除。有勋章引用则不可删。至少 1 个归属。

右列表四层。查询默认三项：名称、积分下限、积分上限；展开无更多也可只这三项（不足 3 个查询字段时不出现展开）。表：图标、名称（链接到编辑）、归属、分类、积分、风险标签、操作。工具栏右：新增勋章。行操作：详情（进编辑页只读头或直接编辑）→ 编辑 → 删除。删除 Confirm：后续不能再发，历史发放保留。

新建/编辑：独立高级表单页。字段见决策表：归属变更清空分类；描述须四段齐全；新建必须上传图标。页脚取消 → 保存。保存回列表保留树与查询。

| 字段 | 场景 | 默认 | 数据源 | 展示／组件 | 选择方式 | 必填与校验 | 联动 |
|---|---|---|---|---|---|---|---|
| 归属 | 表单 | 当前树选中归属 | 归属列表 | Select | 单选 | 必填 | 变则清空分类 |
| 分类 | 表单 | 当前树分类或空 | 该归属下分类 | Select | 单选 | 必填 | |
| 名称 | 表单 | 空 | 手工 | Input | | 必填，同归属不重名 | |
| 积分 | 表单 | 空 | 手工 | InputNumber | | 整数 ≥1 | |
| 图标 | 表单 | 无 | 本地上传 | Upload | 单图 | 新建必填 | |
| 描述 | 表单 | 四段标题模板 | 手工 | TextArea 或分段 | | 四段皆非空 | |

### 发放记录

四层列表。

| 字段 | 场景 | 默认 | 数据源 | 展示／组件 | 必填 | 规则 |
|---|---|---|---|---|---|---|
| 认可编号 | 查询 | 空 | 手工 | Input | 否 | |
| 认可对象 | 查询 | 空 | 手工 | Input | 否 | 姓名或工号 |
| 认可类型 | 查询 | 全部 | 静态 | Select | 否 | 同事认可 / 公司表彰 |
| 所属部门 | 查询 | 空 | 组织树 | TreeSelect | 否 | 展开后 |
| 发起时间 | 查询 | 空 | | RangePicker | 否 | 起止均可空 |
| 状态 | 查询 | 全部 | 静态 | Select | 否 | 四态 |

表列：编号（链接开详情抽屉）、类型、发起人、对象、部门、勋章、积分、事实描述（省略+Tooltip）、状态、发起时间。操作：详情 → 审核（待审核）→ 撤回（已发放，危险最右）。

工具栏：共 N 条；右 导出 → 发布公司表彰。

详情、审核、发布表彰全部用**抽屉**（同一档）。

- 详情：高级详情头（编号、状态、积分）+ 字段 + 风控命中 + 关联编号跳转。已发放页脚：关闭 → 撤回。  
- 审核：同上 + 审核意见。页脚：取消 → 驳回 → 通过并发放。驳回意见必填。  
- 发布：Alert 免审核。表彰对象树多选人必填；勋章仅公司表彰类必填；事由字数 ≥ `minimumReasonLength`。页脚取消 → 确认发放。生成 N 条已发放。

撤回：Modal 说明扣回对象积分并保留日志。确认后状态=已撤回。

### 勋章设置

Tab：积分设置 `points` / 填写设置 `content` / 风控设置 `risk`。

积分设置：查询 统计月份、对象类型、关键词。列：对象、人数、月度额度、月度总额度、月度已使用、进度、操作。新增额度、调整额度用抽屉（对象树组织或人、额度整数≥0、原因选填）。使用明细为列表区内子视图，返回保留月份；可导出 CSV。

填写设置：最少字数 ≥1；占位多行。保存成功 Message。本轮只约束发布表彰。

风控设置：个人提交审核开关（关闭 Confirm：新同事认可将直接发放）。三条规则开关默认开。命中仅详情/审核展示。

## 异常

空、校验保留输入、危险 Confirm、单位进勋章管理空态。加载用现有表格/页 loading。无独立失败页（无接口）。

## 验收

假设集团管理员打开即时激励  
当进入应用  
那么默认数据总览，侧栏四项为数据总览 / 勋章管理 / 发放记录 / 勋章设置  

假设单位管理员  
当打开勋章管理  
那么整页空态，无新增  

假设集团管理员发布公司表彰且事由短于最少字数  
当点确认发放  
那么拦截并提示字数，不写记录  

假设已发放记录  
当确认撤回  
那么状态已撤回，详情可见撤回时间  

假设查询字段展开  
当发放记录超过 3 个查询项  
那么默认只显示前三项 + 查询重置展开
