# 详情页满意度调查按钮 + Tab 精简设计

日期：2026-08-21
状态：已确认

## 背景

详情页 tab 上方已有操作按钮区；满意度调查入口需在按钮区占位，且 tab 内管理能力收窄为查看/编辑既有问卷，不再支持搜索与新建。

## 改动

### 1. 按钮区加「满意度调查」

位置：详情页按钮行，「删除」之前。

- 文案：满意度调查
- 样式：default（非 primary）
- 显示：恒显示
- 点击：`onTabChange('surveys')`，切到「满意度调查」tab
- 不弹新建问卷、不打开 Modal

### 2. 满意度调查 tab 精简

`SurveyList`：

| 移除 | 保留 |
|---|---|
| 工具栏「新建问卷」按钮 | 表格列表 |
| 搜索区（问卷标题 / 状态 / 收集时间 + 查询 / 重置） | 行操作：查看、编辑 |
| | 批量开始收集 |
| | 编辑 / 详情弹窗 |

- 弹窗内部仍可有 create 模式逻辑，但无入口触发 `openEditor()` 无参创建路径
- 列表默认展示该活动全部问卷（无筛选状态）

## 不做

- C 端
- 问卷数据模型
- 其他 tab
- 顶部按钮打开新建弹窗（占位仅切 tab）

## 测试

- `npx tsc --noEmit` 0 错
- `python3 scripts/check_ui_conformance.py --root .` 通过
- 手测：按钮切 tab；tab 无搜索、无新建问卷；查看/编辑仍可用
