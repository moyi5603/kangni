# 活动评分与分享

日期：2026-08-24

## 目标

C 端活动详情支持结束后 5 星评分，以及企微式通讯录分享。管理后台活动详情展示评分指标。

## 评分

- 仅 `activityStatus === '已结束'` 显示评分区。
- 所有人可见平均分（1 位小数）和评分人数；无人评时平均分显示 `—`。
- 仅「已通过」报名可点 1–5 星；一人一条，可改分。键：`activityId + phone`。
- 收藏星标不变。评分用独立五星，不和收藏人数混用。
- 第一次打分 toast「已评分」。本轮不做积分账本。
- Seed：员工开放日（id 1）预置若干同事评分；陈产品默认可评可改。

## 后台

- 详情统计行增加「平均分」「评分人数」。

## 分享

- 详情互动栏常驻「分享」（不限活动状态）。
- 打开 H5 底栏 / PC 弹层：搜索姓名或部门、按部门分组、多选同事、排除当前用户。
- 数据源：`orgPeople`。确认后 toast「已分享给 N 人」，不发送真实消息。0 人选时确定不可用。

## 范围外

- 企微 JS-SDK、复制链接、积分入账、列表页评分。
