# 学习计划（成长地图）改版融合

**日期：** 2026-09-10  
**基线：** `谋发展 后台 · 离线版.html` 成长地图 5 Tab（基本信息 / 任务 / 学员 / 奖励 / 通知）  
**范围：** 在同一对象上融入闯关皮肤、习题任务、进度策略（累计 / 每日）。不新开第二套「学习计划」实体。C 端沿用竖版闯关，按所选预置皮换场景。

## 背景

现网「类型」只描述学员时钟：单次=全员同一起止；周期=每人独立开始/结束。员工端已有写死的竖版闯关（阶段=关卡、顺序锁）。缺口是：后台不能选地图皮；任务只有课/考/讲座，没有题库习题；没有「自然日清进度、第二天重打」的日练。新能力全部挂到现对象，用正交字段，不把「每日」塞进原「类型」。

## 决策

| 项 | 选择 |
|---|---|
| 对象 | 仍是成长地图 / 学习计划，5 Tab 不变 |
| 原「类型」 | 改称**指派模式**：统一窗口 / 滚动周期。语义不变 |
| 进度策略 | 新增：累计 / 每日重置。与指派模式 2×2 都合法。**每日只重置习题闯过态**，课/考/讲座进度跨日保留 |
| 每日内容 | 仅每日：`fixed` / `redraw`。只影响**随机习题**的日种子 |
| 抽题范围 | 全员同题 / 每人异题。只作用于习题每一次抽取 |
| 随机 | **仅习题**。课程、考试（及讲座）只能指定，不能抽 x |
| 锁关 | 永远顺序锁。每日 0 点只清**习题**闯过；按「课/考持久过关 + 当日习题」重算当前关，可能停在最早仍缺当日习题的关 |
| 再闯 | 考试、习题未达标可重复闯，直到达标 |
| 随机习题再闯 | 每一次尝试都重抽，不只按天 |
| 考试再闯 | 同一张指定卷 |
| 手选题再闯 | 同一题集 |
| 闯过 | 考试=该卷及格线；习题=交卷且正确率 ≥ 计划及格线（默认 60%） |
| 阶段通关 | 该阶段全部**必修**过关；选修不挡下一关 |
| 皮肤 | 产品预置多套地图皮，计划选一套；关卡节点跟包走，阶段不单换 |
| 积分 | 课/考/讲座：计划窗口内该任务首次达标才加。习题：每日计划按自然日首次达标才加。未达标再闯不加 |
| 进度同步 | 沿用现网默认。课进度可并入；**不**并入习题当日闯过态 |
| 自然日 | 东八区 0 点切日 |
| 讲座 | 与课程相同：仅指定；完成态跨日保留，不每日重置 |

## 正交轴

```
指派模式     统一窗口 | 滚动周期          （原类型）
进度策略     累计     | 每日重置（只清习题）
每日内容     fixed    | redraw            （仅每日；只打随机习题）
抽题范围     cohort   | personal          （只打习题抽取）
任务来源     课/考/讲座=指定；习题=指定|随机
呈现         预置地图皮（含关卡节点）
```

两套「单次」禁止同名。界面文案：指派模式 vs 进度策略。

## 领域模型

### Plan（增量字段）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| assignMode | `once` \| `rolling` | 是 | 原类型。once=全员同一起止；rolling=每人独立时钟 |
| progressMode | `accumulate` \| `daily` | 是 | 累计=全部任务进度保留；每日=仅习题闯过态按自然日清零，课/考/讲座保留 |
| dailyContent | `fixed` \| `redraw` | daily 时是 | 随机习题是否按日换种子 |
| quizScope | `cohort` \| `personal` | 习题存在时是 | 同一次抽取是否全员同题 |
| quizPassRate | number | 是 | 习题正确率门槛，默认 60，范围 1–100 |
| mapSkinId | string | 是 | 预置皮 ID，默认现网岛屿皮 |
| overtimeAllowed | boolean | 是 | 沿用。只延长**计划窗口**；每日 0 点仍清习题闯过 |
| taskSync | boolean | 是 | 沿用。发布后不可改 |
| progressSync | boolean | 是 | 沿用。仅同步课程等路径进度，不同步习题当日结果 |

`progressMode`、`dailyContent`、`quizScope`：**发布后不可改**（与任务同步同级，改了会打乱已产生的抽取与通关）。`quizPassRate`、`mapSkinId`：发布后可改；及格线对**之后提交的答卷**生效；换皮立即作用于 C 端。

存量地图：`progressMode=accumulate`，无 `dailyContent`，无习题，`mapSkinId=默认岛屿`。

### Stage

沿用。顺序即关卡顺序。无独立 `stageSkinId`。

### Task

| 字段 | 类型 | 说明 |
|---|---|---|
| type | `course` \| `exam` \| `lecture` \| `quiz` | |
| required | boolean | 必修挡锁关 |
| refId | string | 课/考/讲座的内容 ID。习题手选时不用 |
| quizMode | `manual` \| `random` | 仅 quiz |
| questionIds | string[] | 手选题目，≥1 |
| bankId | string | 随机时题库 |
| randomCount | number | 随机题量 x，≥1 且 ≤ 池内可用题数 |

禁止：课程/考试/讲座出现 `quizMode=random` 或 `randomCount`。

### 抽取快照 QuizDraw

一次闯关尝试对应一条。

| 字段 | 说明 |
|---|---|
| planId, userId, taskId | |
| naturalDate | 东八区日期。`redraw` 时写入并进入种子；累计与 `fixed` 可记入记录但不进种子 |
| attemptNo | 每日：该自然日内第几次；累计：该任务终身第几次。从 1 起 |
| questionIds | 本次卷面 |
| seedKey | 见下 |
| submittedAt / scoreRate / passed | 交卷后写 |

**种子 `seedKey`**

拼装：`planId + taskId` →（仅 `daily` 且 `redraw`）`naturalDate` → `attemptNo` →（`personal`）`userId`。

| 模式 | 带日期 | 随机习题效果 |
|---|---|---|
| 累计 | 否 | `attemptNo` 终身累加，每次再闯换题 |
| 每日 + `fixed` | 否 | 隔日 `attemptNo` 从 1 再计；**同一 attemptNo 卷面与昨日相同**。课/考本身不抽题、不清进度 |
| 每日 + `redraw` | 是 | 隔日第 1 次尝试换种子；当天再闯仍随 `attemptNo` 换题 |

同一 `seedKey` 必须得到同一 `questionIds`（先写快照再展示，避免连点抽两次）。

## 三种任务 × 每日 / 随机

| 任务 | 配置 | 累计 | 每日 + fixed | 每日 + redraw | 未达标再闯 |
|---|---|---|---|---|---|
| 课程 | 指定一门 | 学完即过，进度保留 | **进度跨日保留，0 点不清** | 同左 | 继续学同一门，不换课 |
| 考试 | 指定一卷 | 达及格线即过，成绩保留 | **成绩/闯过态跨日保留，0 点不清** | 同左 | 未及格重考**同一卷**；已及格只读 |
| 讲座 | 指定一场 | 完成态保留 | **跨日保留** | 同左 | 不换场 |
| 习题手选 | 指定题集 | 正确率达标即过 | 0 点清闯过态，题集不变 | 同左（手选不换题） | **同一题集** |
| 习题随机 | 题库 + x | 加入后按 attempt 抽 | 每天 attempt 从 1 计；第 1 把与昨日第 1 把同卷；再闯换题 | 隔日第 1 把也换卷；再闯再换 | **每次重抽** |

课程过关：沿用现网完成条件。无「再闯换课」。考试一旦及格，每日计划也不打回未考。

## 闯关状态机（学员 × 计划）

```
进入计划 → 第 1 关可进，其后关锁定
关内必修未全过 → 不可进下一关
考试/习题未达标 → 可再闯本任务（考试已及格则不再考）
关内必修全过 → 下一关解锁
progressMode=daily 且跨自然日 → 仅习题闯过态清零
  → 按序重算：课/考/讲座仍过的关若不含未过必修习题则仍算通关
  → 当前关 = 第一关「必修未齐」（通常是最早仍缺当日习题的关）
计划窗口结束且不允许超期 → 不可再闯
```

例：第 1 关=必修课+必修习题，第 2 关=必修考。学员昨天课、习题、考试都过。今天 0 点后：课、考仍过；第 1 关习题未过 → 锁在第 1 关，先打当日习题，第 2 关考试仍显示已过、只读。

纯课/考关（无必修习题）：一旦过关，每日也不会退回。

每日清的是**习题闯过态 / 当日习题 attemptNo**，不是课进度、不是考试成绩、不是任务定义。历史习题答卷进当日记录，不计入新一天习题通关。

累计模式：全部过关永久，直到任务同步删任务等现网规则。

## 后台界面

### 基本信息

在类型（指派模式）下增加：

- 进度策略：累计 / 每日重置。旁注：每日 0 点只清习题闯过，课程和考试进度保留；顺序锁关按当日习题重算
- 每日内容：仅每日显示。`内容固定` / `随机习题按日换种子`
- 抽题范围：有习题任务时显示，或始终显示并在无随机习题时禁用。`全员同题` / `每人异题`
- 习题及格线：数字，默认 60%
- 闯关皮肤：预置皮卡片选择（缩略图 + 名称），必选，默认岛屿

进度同步：沿用现网。说明：可同步他路径**课程**进度；习题当日是否闯过不同步。

发布后：指派模式、进度策略、每日内容、抽题范围、任务同步只读。

### 任务弹窗

类型：课程 / 考试 / 讲座 / **习题**。

- 课/考/讲座：选择具体内容。无「随机」。
- 习题：来源 `指定题目` / `题库随机`。指定=多选题目；随机=选题库 + x。池内可用题 `< x` 禁止保存。

只读提示随计划总闸变化，例如：`当前：每日重置 · 随机习题按日换种子 · 全员同题 · 及格 60%`。

### 学员 / 奖励 / 通知

沿用。奖励条件「完成全部关卡」= 当前全部阶段必修均过。每日计划下：课/考须历史已过，**习题须当天已过**。积分：课/考首次达标记一次；习题按自然日封顶。再闯失败不加。

勋章「完成全部关卡」同此口径（每日=当天习题也齐）。不另加字段。

## 种子与公平

全员同题：同一 `seedKey`（不含 userId）卷面相同。`redraw` 时种子含自然日；`fixed`/累计不含日期，故全员每天第 N 把同卷。  
每人异题：种子再加 userId。

题库中途删题：已生成的 `QuizDraw` 仍用快照作答。新尝试按当前池抽；池 `< x` 时该任务不可开考，C 端提示「题目不足，联系管理员」，不记失败次数（attemptNo 不占）。

## 与旧字段

| 旧 | 新关系 |
|---|---|
| 任务同步开 | 改题库 / 改 x / 改手选题：存量学员**下一次抽取或下一份未交卷**用新定义。进行中答卷仍用已发快照 |
| 任务同步关 | 已加入学员沿用加入时任务快照（含当时 x 与手选题） |
| 允许超期 | 只延长窗口；不停止每日 0 点清习题 |
| 保密 / 负责人 / 跟踪人 | 不变。跟踪人只读含皮肤与进度，不能改总闸 |
| 完成条件 | 沿用计划级完成条件；关卡锁另按必修计算 |

## 预置皮肤

至少 3 套，上线前做进资源，不开放运营上传底图：

1. `island`：现网竖版岛屿（默认，存量用它）
2. `city`：城市路线
3. `minimal`：简约节点（弱游戏）

每套含：地图底、关卡三种态（锁定 / 进行中 / 已通关）、通关动效可共用一套。计划只存 `mapSkinId`。

## 异常

| 场景 | 处理 |
|---|---|
| 随机 x > 池 | 表单不通过 |
| 运行时池不足 | 不能开考，attempt 不占，提示管理员 |
| 每日跨日正在做习题 | 该份习题交卷作废；新一天 attempt=1。已判定的习题卷留历史。课/考进行中进度不清 |
| 未达标交卷 | 习题：记 attempt、正确率，关不亮，可再闯。考试：同左，卷不变 |
| 达标后再进该任务 | 课/考：只读（含每日跨日）。习题累计：只读。习题每日：当天只读，跨日当未过 |
| 关内仅课/考无习题 | 过关后每日不退回该关 |
| 发布后改进度策略 | 禁止 |
| 无习题却配 redraw | 允许保存；redraw 无效果直到出现随机习题 |
| 选修考试未过 | 不挡下一关 |

## 非目标

- 课程/考试（及讲座）按日清进度
- 课程/考试随机抽内容
- 阶段独立换节点皮、运营自定义上传地图
- 拆成两个产品对象
- 改指派模式语义（统一窗口 vs 滚动周期）
- 习题及格线按任务分别配（本版计划级）
- 时区除东八区以外

## 验收要点

1. 新建计划能配指派模式 + 进度策略；每日才出现每日内容。
2. 任务可加习题：手选或题库随机 x；课/考/讲座无随机入口。
3. 员工端顺序锁关；考试/习题未达标可再闯；随机习题每次尝试题目不同，全员同题时同一 attemptNo 同卷。
4. 每日 0 点（东八区）只清习题闯过态；课程进度、考试成绩跨日仍在。锁关重算到最早缺当日必修习题的关。`fixed` 时随机习题同一 attemptNo 隔日同卷；`redraw` 时隔日第 1 把换卷。
5. 习题交卷正确率 < 及格线不算过关；≥ 及格线且必修齐才开下一关。
6. 计划能选预置地图皮，C 端换底与节点，锁关逻辑不变。
7. 存量地图打开即累计 + 默认岛屿皮，行为与改版前一致。
8. 发布后不可改进度策略 / 每日内容 / 抽题范围 / 任务同步。
