# 报名卡左侧封面

**日期：** 2026-08-19  
**状态：** 已确认，待实现  
**范围：** H5 与 PC 的首页「我的活动」预览卡、以及「我的报名」列表卡。发现活动、详情、后台管理端不改。  
**关联：** `docs/superpowers/specs/2026-08-18-h5-employee-activity-portal-design.md`、`docs/superpowers/specs/2026-08-19-pc-employee-activity-portal-design.md`

## 背景与目标

首页「我的活动」和「我的报名」目前只有标题、日期、地点，员工要靠文字辨认活动。发现活动已经有封面。目标：在报名相关卡片上露出活动封面，加快识别，同时保持紧凑列表，不改成发现活动那种 16:9 大卡。

## 方案

在现有报名卡上加左侧小方封面。H5 与 PC 各自改各自的卡片，不抽公共 SignupCard，不合并两套壳。

## 出现位置

| 表面 | 页面 | 卡片 |
|---|---|---|
| H5 | `#/c/h5` 我的活动预览 | `HomeSignupPreviewCard` |
| H5 | `#/c/h5/my` 待参加 / 已结束 | `SignupCard` |
| PC | `#/c/pc` 我的活动预览 | `HomeSignupPreviewCard` |
| PC | `#/c/pc/my` 待参加 / 已结束 | `SignupCard` |

预览条数、查看全部、失效分组规则不变。

## 布局

有效活动卡从左到右：

1. 固定正方形封面，边长 72px，圆角 8px。
2. 右侧原有文案：标题、日期、地点；「我的报名」仍保留报名类型、报名状态、活动状态 pill。
3. 最右侧仍是 chevron（失效卡没有 chevron，也不加封面）。

封面 `object-fit: cover`，不拉伸。卡片高度随右侧文案，封面垂直居中，不把预览卡撑成发现活动大卡。

## 图片与空态

- 有 `activity.coverUrl`：渲染 `<img src={coverUrl} alt="">`。装饰图，标题已在旁边。
- 无 `coverUrl`，或图片 `onError`：显示色块 fallback（H5 复用 `.c-cover-fallback`；PC 在 `.c-pc-shell` 下做同等色块）。方框始终占位，避免无图时文字左移。
- 封面上看不到活动类型角标。类型已在报名详情或发现活动里出现。
- 失效记录没有关联活动：保持「活动已失效」虚线卡，不加封面、不加假图。

## 不做

- 不改发现活动网格 / 竖列大图。
- 不改详情封面、报名弹窗、后台。
- 不把 H5 与 PC 合成一套响应式组件。
- 不在首页预览卡上新加类型、社交数字或 CTA。

## 测试

- 用已有 seed 报名（例如活动 2）渲染首页预览：「我的活动」卡包含该活动 `coverUrl`。
- 「我的报名」有效卡包含 `coverUrl`；失效卡 HTML 不含 `<img>`。
- 现有预览条数、查看全部、失效文案测试继续通过。
