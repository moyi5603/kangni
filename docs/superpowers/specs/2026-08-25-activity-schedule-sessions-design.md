# 活动举办方式与场次

日期：2026-08-25

## 目标

公司活动支持三种举办方式：单次、周期、系列。活动与场次 1:N。报名时间活动级统一；活动时间按场次。多场报名勾选场次。

## 不做什么

- 每场独立报名窗口
- 系列「整场必须全选」
- 周期无限循环
- 改兴趣小组模块

## 数据

- 现有 `type`（公司活动等）不变
- 新增 `scheduleType`: `once` | `recurring` | `series`，默认 `once`
- 场次 `ActivitySession`: `id`, `startAt`, `endAt`
- 周期：`repeatWeekday`（1–7 周一至周日）、`timeStart`/`timeEnd`（HH:mm）、`cycleStart`/`cycleEnd`（日期）→ 生成场次
- `activity.startAt` / `endAt` = 全部场次最早开始 / 最晚结束，供筛选
- 报名 `answers.场次` = 选中场次 id，顿号拼接

## 表单

- 分类下增加举办方式 Radio（编辑不可改）
- 单次：现有活动时间 RangePicker
- 周期：周几、每日时段、周期起止日
- 系列：至少 2 场，每场活动时间 RangePicker
- 报名时间始终活动级一份

## 展示

- 单次：报名、活动时间与现在相同
- 周期列表/详情活动时间：`每周三 14:00-16:00（2026-08-26～2026-10-28，共 n 场）`
- 系列：`首场 {start} ~ {end} · 共 n 场`
- 详情（周期/系列）：场次表（第 n 场、活动时间）
- C 端报名：多选场次，至少 1 场

## 校验

- 周期必须生成至少 1 场
- 系列至少 2 场，每场结束不早于开始
- 多场报名未选场次不可提交
