# 报名 Tab：人表 + 场次列 + 可搜索场次筛

日期：2026-08-31  
状态：已确认  
范围：管理后台「活动」「兴趣圈」活动详情 **报名 Tab**。不改 C 端、添加/导入是否选场次、Header 指标。

## 决策

周期/系列报名以**人表**为主。场次是人的属性和查询条件。不要场次概况表、不要横滑卡片、不要场次下级页。

单次活动：无场次列、无场次筛（与现网一致）。

## 查询

周期/系列增加 **场次** Select：

- 选项：`全部场次` + `第 n 场 YYYY-MM-DD HH:mm ~ YYYY-MM-DD HH:mm`（沿用 `sessionSelectOptions`）
- 默认全部；`showSearch`，按选项文案过滤（场次号、日期均可）
- 点「查询」才生效，与现有 SearchPanel 一致
- 活动查询字段顺序：姓名、部门、场次、状态；报名时间放展开后（保证收起态能看到场次）
- 兴趣圈：姓名、部门、场次（有场次时）；部门选项与活动应用同一套 `departmentOptions`

## 人表

- 活动：场次列只显示「第 n 场」，「场次时间」单独一列 `startAt ~ endAt`
- 指定场次：只保留该场的行
- 一人报多场：多行，筛某场只出现该场那一行

## 删除

查询区与人表之间的场次概况 Card/Table（`共 N 场`、点行筛选）整段删除。

## 验收

1. 单次：无「全部场次」、无概况「共 N 场」。
2. 周期/系列：有「全部场次」且 Select 可搜索；人表有场次列；无概况表头「报名人数」「名额」。
3. 筛某场后人表只含该场；一人报多场为多行。
4. 活动收起查询时仍能看到场次条件。
