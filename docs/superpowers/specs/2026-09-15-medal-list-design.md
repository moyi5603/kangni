# 勋章管理列表

**日期：** 2026-09-15  
**规范：** `build-ant-design-b2b-app`（列表四层、查询四列网格、弹窗取消→保存、行操作顺序）  
**对照：** 云悦 [badge/list](https://admin.joybenefits.cn/micro/grandriver-union-admin/badge/list) 截图（列表 + 创建弹窗）  
**前置：** `docs/superpowers/specs/2026-09-15-medal-app-design.md` 已挂独立应用 `medal`  
**范围：** 管理端「勋章管理」真列表、创建/编辑弹窗、有效/失效、删除。发放记录入口禁用。本轮不接活动 `medalLibrary`、不打卡选库、无权限、无 C 端。

## 背景

源站是查询与「创建勋章」同一行、弹窗底栏「保存 | 取消」、四查询项全展开。这些与 B 端规范冲突。业务字段、列、行操作跟随源站；页面骨架走规范 `ListPage`。

## 决策

| 项 | 选择 |
|---|---|
| 模块 | 新建 `src/features/medal`，内存 mock |
| 默认页 | `#/medal/medal-list` 真列表，替换占位 |
| 创建/编辑 | 同一 Modal，字段 ≤6 |
| 发放记录 | 行按钮禁用，Tooltip「后续开放」，无页面 |
| 活动勋章库 | 不改、不同步 |
| 顶栏 / 权限 / C 端 | 不做 |

## 信息架构

侧栏仍一个一级叶子：勋章管理。

| Hash | 行为 |
|---|---|
| `#/medal`、`#/medal/medal-list`、未知页 | 列表 |
| `#/medal/medal-create` | 列表 + 打开创建弹窗 |
| `#/medal/medal-edit/:id` | 列表 + 打开编辑弹窗；无记录则列表 + 提示不存在 |
| `#/medal/medal-detail/:id` | 回落列表（无详情页） |

关闭弹窗后 hash 回到 `#/medal/medal-list`，保留查询。侧栏始终高亮 `medal-list`。

面包屑：`勋章 > 勋章管理`。标题：勋章管理。副标题：维护勋章素材，供活动、打卡等业务选用（本轮仅本应用内维护）。

## 实体 `MedalRecord`

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `id` | string | 系统 | 新记录生成 | 行键 |
| `name` | string | 是 | 空 | ≤30，列表名称列 |
| `imageUrl` | string | 是 | 空 | 上传后的 data URL 或静态图 |
| `app` | `MedalApp` | 是 | `通用` | 所属应用 |
| `description` | string | 否 | 空 | ≤100 |
| `status` | `有效` \| `失效` | 系统 | `有效` | 创建后有效；行内切换 |
| `creator` | string | 系统 | 当前演示用户「北玛三十度」 | 不可编辑 |
| `createdAt` | string | 系统 | 创建时刻 `YYYY-MM-DD HH:mm:ss` | 不可编辑 |

`MedalApp`：`通用` \| `活动` \| `课发展` \| `评优活动` \| `文化打卡`。文案与源站下拉一致（「课发展」不改成「课程」）。

种子：截图可见名称（明星员工、服务标兵、价值观典范、匠心品质、成长之星、卓越贡献、成长启航、协作共赢、创新进取，及至少一条描述被截断的「客户…」类记录），补满约 18 条以便分页。图标可用现有 SVG data URI。所属应用、创建人、时间按截图可辨部分对齐，其余合理填充。

## 列表页

四层：面包屑 → 标题行 → 查询 → 表格。使用 `ListPageHeading`、`SearchPanel`、`ListTableCard`、`TableRowActions`。

### 查询

字段数 4，默认收起只显示前 3 项，第 4 项「创建时间」在展开后出现。按钮：查询（Primary）→ 重置 → 展开/收起。

| 字段 | 场景 | 默认值 | 数据源 | 展示／组件 | 选择方式 | 必填与校验 | 联动／特殊规则 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 勋章名称 | 查询 | 空 | 用户输入 | Input | 文本 | 否 | 包含匹配 `name` |
| 所属应用 | 查询 | 全部 | `MedalApp` + 全部 | Select | 单选 | 否 | 空=全部 |
| 勋章状态 | 查询 | 全部 | 有效/失效 + 全部 | Select | 单选 | 否 | 空=全部 |
| 创建时间 | 查询 | 空 | 系统日期 | RangePicker | 范围 | 否 | 两端可空；按 `createdAt` 落在闭区间（日粒度） |

查询顺序与源站一致（名称优先搜），与表列不完全同序。理由：源站把检索关键词放第一位，表列把图标/名称/描述放识别区。登记为特殊顺序。

提交查询才过滤。重置清空四项并查第一页。筛选变化回第一页。查询状态同步 URL query（`name`、`app`、`status`、`from`、`to`、`page`、`pageSize`）。

### 表格工具栏

左：`共 N 条`（当前过滤结果）。无批量。右：主按钮「创建勋章」。

### 列

| 列 | 对齐 | 链接 | 溢出 | 说明 |
|---|---|---|---|---|
| 勋章图标 | 左 | 否 | 否 | 40px 图，无图占位 |
| 勋章名称 | 左 | 否 | 省略 + Tooltip | 本轮名称不进详情 |
| 勋章描述 | 左 | 否 | 省略 + Tooltip | 空显示 — |
| 状态 | 左 | 否 | 否 | Tag：有效 success / 失效 default |
| 创建人 | 左 | 否 | 省略 + Tooltip | |
| 所属应用 | 左 | 否 | 否 | |
| 创建时间 | 左 | 否 | 否 | |
| 操作 | 右 | — | — | 固定右 |

无选择列。分页：默认 10 条/页，可改 10/20/50。空：无数据 vs 筛选无结果分开文案。

### 行操作

规范顺序：编辑 → 发放记录 → 设为失效/设为有效 → 删除。`actionsMaxVisible` 为 3：前三项直出，删除进「更多」。不改全局规范去迁就源站四按钮直出。

| 操作 | 行为 |
|---|---|
| 编辑 | 打开编辑弹窗，hash `#/medal/medal-edit/:id` |
| 发放记录 | `disabled`，Tooltip「后续开放」 |
| 设为失效 | 当前有效时显示；确认后 `status=失效` |
| 设为有效 | 当前失效时显示；确认后 `status=有效` |
| 删除 | 危险确认：删除后不可恢复；确认删除 |

启停与删除均二次确认。成功 `message.success`。

## 创建 / 编辑弹窗

同一 Modal。标题：创建勋章 / 编辑勋章。无全屏按钮。表单标签同行，标签宽 112px。

| 字段 | 场景 | 默认值 | 数据源 | 展示／组件 | 选择方式 | 必填与校验 | 联动／特殊规则 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 勋章图片 | 表单 | 无 | 本地上传 | Upload 方图 + | 单图 | 必填 | 图片类型；失败保留已选 |
| 勋章名称 | 表单 | 空 | 用户输入 | Input | 文本 | 必填，≤30 | |
| 所属应用 | 表单 | 通用 | `MedalApp` | Select | 单选 | 必填 | 选项顺序同下拉截图 |
| 勋章描述 | 表单 | 空 | 用户输入 | TextArea | 文本 | 否，≤100 | 计数 0/100 |

底栏右对齐：**取消 → 保存**。保存中防重复提交。校验失败留在弹窗。编辑不改 `creator`、`createdAt`、`status`（状态只走行操作）。

关闭弹窗：取消、遮罩、Esc 均丢未保存内容（字段少，不做离开提醒）。关闭后回到列表 hash，保留查询。

## 路由接入

`App.tsx`：`medal-list` / `medal-create` / `medal-edit` / `medal-detail` 渲染 `MedalListPage`，不再走 `PlaceholderPage`。页内按 hash 开关弹窗。

## 测试与验收

- 查询收起三项 + 展开见创建时间；查询/重置/分页 URL 同步。
- 创建保存后出现在列表第一页顶部（或按创建时间倒序，spec 定为 **创建时间倒序**）。
- 编辑回填；失效后状态 Tag 变灰，行操作改为设为有效。
- 删除确认后行消失。
- 发放记录不可点，有 Tooltip。
- 弹窗底栏取消在左、保存在右。
- `check_ui_conformance.py` 对 `features/medal` 通过。
- `navigation.test.ts` 原 medal 解析用例仍过。

## 不做

发放记录页、批量、导出、权限、C 端荣誉墙、与活动/打卡/评优选库打通、顶栏直显、改 `actionsMaxVisible`、源站「保存|取消」和查询行内创建按钮。
