# 活动 / 兴趣圈 活动详情 Header 统一

日期：2026-08-31  
状态：已确认  
范围：管理后台「活动」应用活动详情、「兴趣圈」应用活动详情。仅 Tab **上方** Header 卡片。C 端、列表、详情 Tab 内 Descriptions、业务规则不改。

## 背景

两边都是高级详情页：面包屑 → Header 卡 → Tabs。Header 骨架已分叉：

- 活动：封面 | 标签+标题+操作 → 摘要 → 指标；封面 `object-fit: cover` 随右侧撑高，易裁成方图。
- 兴趣圈：封面+标题 与 操作左右拆开；摘要铺满整卡；指标是纯文本；终止/删除常驻禁用。

运营要两边同一套页面结构。封面必须保持原图比例，禁止裁成方图。

## 页面结构

自上而下不变：面包屑 → Header 卡 → Tabs。

Header 卡内部：

```
┌ 封面列(宽 240) ┬ 标签（分类 → 生命周期 → 审核）
│ 顶对齐         │ 标题 ……………… 操作（主左、次右、危险最后）
│ 不随右侧撑高    │ 摘要 5 行
│                └ 指标 Statistic 行
```

窄屏：封面在上，身份区在下；操作仍与标题同行，空间不够时按钮组换行靠右。

## 封面

- 列宽固定 **240px**，`align-items: flex-start`，**不** `stretch` 到与右侧同高。
- 有图：`<Image>` 宽不超过 240px，高随原图比例（`width: 100%; height: auto`）。禁止 `object-fit: cover`、禁止写死 1:1。
- 竖图设 `max-height: 180px`，超出部分用 `object-fit: contain` 完整显示，两侧可留白，不裁切。
- 圆角 8px。点击仍走 antd Image 预览。
- 无封面：占位 **240×135（16:9）**，灰底文案「暂无封面」，不是方图。

## 标签

顺序固定：分类 → 生命周期 → 审核状态。  
审核为「已通过」或「无需审核」时不显示审核 Tag。

## 摘要（固定 5 行）

| 行 | 文案 | 空值 |
|---|---|---|
| 1 | 活动时间：… | 格式沿用各应用现有 `format*ActivityTime` |
| 2 | 报名时间：… | 沿用现有 `format*SignupTime` |
| 3 | 活动地点：… | `—` |
| 4 | 报名截止时间：… | `signupEndAt`，空为 `—` |
| 5 | 活动终止时间：… | `terminatedAt`，空为 `—` |

兴趣圈「所属兴趣圈」只在详情 Tab，不进 Header。

## 操作

顺序固定。无权限或不满足条件则按表隐藏或禁用，不另加按钮。

| 顺序 | 按钮 | 活动应用 | 兴趣圈应用 | 强调 |
|---|---|---|---|---|
| 1 | 审核 / 提交审批 / 编辑 | 三选一作主按钮（现有 `canReview` / `canSubmit`，否则编辑） | 无审核入口，主按钮为编辑 | primary，组内最左 |
| 2 | 编辑 | 仅当主按钮不是编辑时显示 | 不重复 | default |
| 3 | 复制创建 | 恒显示 | 有 `onCopy` 才显示 | default |
| 4 | 签到码 | 仅 `checkInEnabled`，切到签到码 Tab | 同左 | default |
| 5 | 截止报名 / 恢复报名 | 现有 canClose / canReopen，互斥 | 同左 | default |
| 6 | 终止活动 | 仅 `canTerminate*` 时显示；不可终止 **隐藏**（不摆禁用） | 同左，去掉常驻禁用+Tooltip | danger |
| 7 | 删除 | 可删则确认后删除并返回列表；不可删则禁用并 Tooltip 说明 | 同左（已有报名不可删） | danger，最右 |

终止、删除、截止/恢复、提交审批均用 Modal 确认（兴趣圈终止不再用 Popconfirm）。终止文案已统一：`未举办场次不再进行，且不可恢复为进行中。`

## 指标

同一 `Statistic` 行，公共三项在左，应用扩展在右。

| 指标 | 活动 | 兴趣圈 |
|---|---|---|
| 报名人数 | 非已取消人数；有限额时 suffix `/ 限额` | `signedCount`；有 `capacity` 时 suffix `/ capacity` |
| 评论数 | 现有 related comments | 该活动评论条数 |
| 精彩瞬间数 | 现有 moments | 该活动瞬间条数 |
| 待审核报名 | 现有 pending | 无，不显示 |
| 报名额使用率 | 现有 quotaUsage，无限额 `—` | 无，不显示 |
| 平均分 / 评分人数 | 现有 rating | 无，不显示 |
| 点赞 | 无，不显示 | `likeCount` |

不强行给兴趣圈加评分/待审，不强行给活动加点赞。

## 实现约束

- 抽展示型 `ActivityDetailHeader`（或同名）壳：封面、标签、标题、操作 slot、摘要、指标 slot。两个详情页传入数据与按钮，不把两边业务 store 揉进一个文件。
- 共用 CSS 类名沿用 `activity-detail-header-*`，改封面规则后两边一起生效。
- 详情 Tab、签到码/报名等 Tab、列表页不在本次范围。

## 验收

1. 两边 Header DOM 顺序一致：封面 → 标签 → 标题+操作 → 5 行摘要 → 指标。
2. 横图、竖图均保持原比例，不被裁成方图；无封面是 16:9 占位。
3. 活动应用审核/提交/编辑主按钮逻辑与现网一致；兴趣圈主按钮为编辑。
4. 不可终止时两边都没有终止按钮；不可删除时删除禁用。
5. 指标公共三项都在；活动有待审/使用率/评分，兴趣圈有点赞。
6. 现有详情页单测按新结构改断言（封面 class、按钮顺序、不出现方图 cover）。
