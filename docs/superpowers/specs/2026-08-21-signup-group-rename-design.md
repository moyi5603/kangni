# 报名设置改分组设置、报名类型改分组名称（管理端）

**状态：** 待实现  
**日期：** 2026-08-21  
**范围：** 管理端活动新建/编辑、详情、报名名单与导入的文案。数据字段 `signupSettings[].type`、`signupType` 不改。规则设置 Tab「报名设置」、C 端、卡片标题「报名设置」不改。

## 背景

运营把每条报名配置当作一个「分组」。现有「报名设置 1 / 报名类型」与业务口径不一致，需要统一为「分组设置 / 分组名称」。

## 决策摘要

| 项 | 选择 |
|---|---|
| 表单卡片 | `报名设置 N` → `分组设置 N` |
| 表单字段 | `报名类型` → `分组名称` |
| 详情 | `报名类型 N` → `分组名称 N` |
| 名单/导入界面 | 「报名类型」→「分组名称」 |
| CSV 模板/解析 | 只认新表头「分组名称」 |
| 数据字段 | 不改 |
| 外层卡片标题「报名设置」 | 不改 |
| 规则页 Tab「报名设置」 | 不改 |
| C 端 | 不改 |

## 新建/编辑表单 `ActivityFormPage`

- 子卡标题：`报名设置 ${index + 1}` → `分组设置 ${index + 1}`
- 字段 label：`报名类型` → `分组名称`
- 校验：`请输入报名类型` → `请输入分组名称`；`报名类型不超过 10 个字` → `分组名称不超过 10 个字`
- 占位：`请输入报名类型名称` → `请输入分组名称`
- 按钮：`添加报名设置` → `添加分组设置`；`删除此报名设置` → `删除此分组设置`
- 空列表校验：`请至少添加一条报名设置` → `请至少添加一条分组设置`

## 详情 `ActivityDetailPage`

- `报名类型 ${index + 1}` → `分组名称 ${index + 1}`

## 报名名单与导入 `ActivityRelatedListPage`

- 表格列 `报名类型` → `分组名称`
- 筛选项 `报名类型` → `分组名称`
- 手动新增表单 `报名类型` → `分组名称`；校验 `请选择报名类型` → `请选择分组名称`；占位同步
- 导入跳过文案：`的报名类型不在该活动中` → `的分组名称不在该活动中`
- 导入 extra：`姓名、手机号、部门、报名类型` → `姓名、手机号、部门、分组名称`；`已配置的报名类型` → `已配置的分组名称`

## CSV `signupImport.ts`

- 模板表头：`姓名,手机号,部门,报名类型` → `姓名,手机号,部门,分组名称`
- 解析 `header.indexOf('报名类型')` → `header.indexOf('分组名称')`
- 表头错误：`表头须包含：姓名、手机号、部门、报名类型` → `...、分组名称`
- 行错误：`第 N 行缺少报名类型` → `第 N 行缺少分组名称`

旧模板导入直接报表头错误，不兼容旧表头。

## 测试与验收

现无 `signupImport` 单测，本轮补：

1. 新表头能解析
2. 旧表头「报名类型」报「表头须包含：姓名、手机号、部门、分组名称」
3. 行缺分组名称报对应文案

改完跑活动单测 + `check_ui_conformance.py`。

可观察：表单/详情/名单/导入全部显示分组设置、分组名称；旧 CSV 模板导入报新表头错。
