# 普通投票题型组件

**日期：** 2026-08-25  
**状态：** 待用户审阅  
**规范：** `build-ant-design-b2b-app`  
**关联：** 修订 `2026-08-25-voting-app-design.md` 中普通投票的选项模型。评选投票结构保留，仅员工候选人增加可选头图。  
**范围：** B 端表单 / 详情 / 结果 / 种子与模型。不做 C 端作答、不做拖拽排序、不改考试试题库。

## 背景

普通投票原先一场只有一组文字选项。现改为问卷：一场可添加多道题，题型为单选、多选、图片单选、图片多选、问答题、打分题。

## 决策摘要

| 项 | 选择 |
|---|---|
| 结构 | 一场普通投票 = 多题问卷 |
| 添加 | 六个按钮并排，点哪个加哪类题 |
| 图片选择题 | 图必填，文案可选 |
| 打分 | 可配最低分、最高分（整数，最低 < 最高） |
| 每日额度 | 仍按整卷提交次数，不按题 |
| 评选 | 仍员工/作品列表；员工可上传头图 |
| 结果 | 按题统计 |

## 实体

普通投票不再使用 `VoteOption`。改用 `VoteQuestion` + `VoteChoice`。评选仍用 `VoteOption`，`kind` 仅 `员工` | `作品`。

### VoteQuestion（仅普通投票）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | number | 系统 | |
| `campaignId` | number | 系统 | |
| `sortOrder` | number | 系统 | 从 0 |
| `type` | 见下 | 是 | 创建后题目内不可改题型（删了重加） |
| `stem` | string | 是 | 题干 ≤200 |
| `choices` | VoteChoice[] | 条件 | 选择类 ≥2 |
| `minScore` | number | 条件 | 打分题，整数，默认 1 |
| `maxScore` | number | 条件 | 打分题，整数，默认 5，须 > minScore，范围 0–10 |

题型：`单选` | `多选` | `图片单选` | `图片多选` | `问答题` | `打分题`。

### VoteChoice

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | number | 系统 | 题内唯一 |
| `sortOrder` | number | 系统 | |
| `label` | string | 条件 | 单选/多选必填 ≤40；图片题可选 ≤40 |
| `imageUrl` | string | 条件 | 图片单选/图片多选必填 data URL 或静态路径 |

同一题内：文字选项 `label` 去空白后不重复。图片题无文案时不要求文案唯一。

约束：每场普通投票 1–20 题。选择类每题 2–10 个选项。问答题无 `choices`。打分题无 `choices`。

### VoteOption（评选，增量）

员工增加 `imageUrl?: string`（可选头图，data URL / 路径）。作品封面规则不变。

### 提交

原 `VoteBallot`（一张票绑一个 optionId）改为：

**VoteResponse**

| 字段 | 说明 |
|---|---|
| `id` | |
| `campaignId` | |
| `voterId` / `voterName` | 匿名仍保存 id，展示打码 |
| `submittedAt` / `dayKey` | 整卷一次提交 |

**VoteAnswer**

| 字段 | 说明 |
|---|---|
| `id` | |
| `responseId` | |
| `questionId` | |
| `choiceIds` | 单选 0–1 个；多选 / 图片多选 0–n 个 |
| `text` | 问答题 |
| `score` | 打分题，落在 [minScore, maxScore] |

`wouldExceedDailyQuota` 对普通投票：当天该人 `VoteResponse` 条数 ≥ `dailyQuota` 则超额。`allowStackOnSameOption` 普通投票不使用（表单隐藏该开关）。评选仍按候选人选票 + 连投开关。

评选继续用旧 `VoteBallot`（`optionId`）。store 里两种提交分集合：`responses`（普通）与 `ballots`（评选）。

## 状态与编辑权

活动级规则不变。题目：

- 未开始：可增删改题、改选项
- 进行中：可新增题；有答案的题不可删、不可改题型/选项身份（选择项 id / 图片题换图算身份）；题干可改；打分上下限有答案后不可改
- 已结束：只读

## 列表

普通投票「选项数」列改为「题目数」。评选仍显示候选项数。总票：普通=提交次数，评选=选票数。

## 表单

普通投票「题目」Card：

- 工具条六个按钮（主操作区，从左到右）：单选、多选、图片单选、图片多选、问答题、打分题。点即追加一题卡片。
- 题卡片：题号、题型 Tag、题干 Input、按类型子字段、上移 / 下移 / 删除。
- 单选/多选：Form.List 文字选项，至少 2。
- 图片单选/多选：每项 Upload 必填 + 文案可选。
- 问答：仅题干。
- 打分：最低分、最高分 InputNumber。
- 无题不可保存。

评选：员工行 TreeSelect + 可选头图 Upload。作品不变。

切活动类型仍确认后清空：普通清空题目；评选清空候选人。

## 详情 / 结果

详情：普通按题只读列出题干、题型、选项（图片缩略图）或分制。评选候选人带员工头图。

结果：

- 选择类（含图片）：该题选项票数、占比、竞赛名次。图片题展示缩略图。
- 多选：一票可计多个选项，占比分母=该题答案里出现的选项人次（不是提交人数）。
- 问答：表格列出提交时间、投票人（可匿名）、文本。无则「暂无作答」。
- 打分：均分（一位小数）、各分值人数表。
- 未开始且无提交：空态「尚未开始，暂无投票」。

## 种子

- 普通投票至少 1 场含 ≥3 种题型（含图片题、问答、打分）且有提交。
- 另保留一场未开始普通投票（仅单选，无提交）。
- 评选进行中那场：至少一名员工带头图。
- 列表「题目数 / 总票」能对上。

## 测试

- `voting.test.ts`：问卷额度按提交次数；选择类排名；打分均分；多选一人多选项计数。
- `voteStore.test.ts`：普通投票存 questions；删活动级联 questions + responses；评选 ballots 仍级联。
- 表单页：六个添加按钮文案；不含「导入人群」。
- 详情结果：混题型种子能看到问答文本或打分均分、图片题标题/图。

## 不做

C 端作答页、拖拽排序、题目复制、必答开关、跳题逻辑、考试题库复用、评选改问卷。
