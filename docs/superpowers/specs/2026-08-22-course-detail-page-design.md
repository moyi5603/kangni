# 课程独立详情页

**状态：** 已定稿  
**日期：** 2026-08-22  
**范围：** B 端课程列表「详情」改为独立高级详情页，字段对齐编辑页。不改 C 端，不在详情里改数据。

## 决策

| 项 | 选择 |
|---|---|
| 内容档 | 对齐编辑：封面、基本信息、学习设置、目录明细、介绍、评论配置 |
| 承载 | 独立页（编辑已是独立页，同对象必须同承载） |
| 形态 | 高级详情：面包屑 + Header（名+状态+操作）+ Card 分组 |
| 操作 | Header 右：编辑（主）→ 评论管理 → 返回 |
| 评论配置 | 新建/编辑页 Card 可改；详情 Tab「详情」内开关即时保存；列表「更多」仍可改 |
| 学习记录 | 详情 Tab「学习记录」，按当前课程名过滤 |

## 路由

`#/training/course-detail/:id`  
`siderSelectedKey`：`course-detail` → `training-courses`

列表课程名链接与行内「详情」进入此页。去掉详情 Modal。

## 结构

1. 面包屑：`课程 > 课程管理 > {课程名} > 详情`
2. Header：左名称 + 发布状态 Tag；右操作
3. Card：基本信息 / 学习设置 / 课程目录 / 课程介绍 / 评论配置

`Descriptions` 一行三列、inline；窄屏两列/一列。空值 `—`。

## 字段

**基本信息：** 封面图（`Image`，无则 `—`）、类型 Tag、分类、名称、标签、适用对象、创建人、创建时间、最后修改时间  

**学习设置：** 学习过程  

**课程目录：** 只读表：序号、封面、名称、类型、课件时长、学时（右对齐）、是否必学（是/否）。无拖拽/增删。空：`Empty`「暂无课件」。课件缺失：名称 `课件 #{id}`，其余 `—`  

**课程介绍：** 渲染 `introHtml`（`rich-text-preview`）。空：`Empty`「暂无介绍」  

**评论配置：** 评论 / 评论审核 / 点赞 / 收藏 → 开（绿）/ 关（灰）

## 异常

- 无 id / 不存在：Empty「课程不存在或已删除」+ 回列表
- 分类已删：`—`
- 封面坏链：`Image` fallback

## 非目标

详情内改评论配置、改目录、发布/撤销/删除；C 端详情。
