# 考试应用入口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在管理端「全部应用」增加独立应用「考试」，左侧五个一级占位菜单，页面沿用现有 `PlaceholderPage`。

**Architecture:** 只改 `src/app/navigation.ts` 元数据：`applications` 增加 `exam`，`applicationMenus['exam']` 五个一级叶子。不新建 `features/exams`，不改 `App.tsx`（`fileText` 与 `PlaceholderPage` 兜底已存在）。`exam` 插在 `care` 正前方（当前即 `skills-contest` 之后）。

**Tech Stack:** React 19、antd 6、Vitest、现有 hash 路由 `parseLocationHash` / `toLocationHash`。

**Spec:** `docs/superpowers/specs/2026-08-19-exam-app-design.md`

```ts
describe('exam application', () => {
  it('registers the app under 员工与组织 with exam-overview as default', () => {
    expect(getApplication('exam')).toEqual({
      key: 'exam',
      label: '考试',
      category: '员工与组织',
      icon: 'fileText',
      defaultPage: 'exam-overview',
    });
  });

  it('sits immediately before 人文关怀', () => {
    const keys = applications.map((item) => item.key);
    expect(keys.indexOf('exam')).toBe(keys.indexOf('care') - 1);
    expect(keys.indexOf('exam')).toBeGreaterThan(keys.indexOf('training'));
  });

  it('uses five first-level menus with no children', () => {
    expect(applicationMenus['exam']).toEqual([
      { key: 'exam-overview', icon: 'dashboard', label: '概览' },
      { key: 'exam-list', icon: 'unorderedList', label: '考试管理' },
      { key: 'exam-categories', icon: 'appstore', label: '分类管理' },
      { key: 'exam-tags', icon: 'tags', label: '考试标签' },
      { key: 'exam-rules', icon: 'fileText', label: '规则设置' },
    ]);
  });

  it('parses a leaf hash', () => {
    expect(parseLocationHash('#/exam/exam-list')).toEqual({
      application: 'exam',
      page: 'exam-list',
    });
  });

  it('falls back to exam-overview when page is missing or unknown', () => {
    expect(parseLocationHash('#/exam')).toEqual({
      application: 'exam',
      page: 'exam-overview',
    });
    expect(parseLocationHash('#/exam/not-a-page')).toEqual({
      application: 'exam',
      page: 'exam-overview',
    });
  });

  it('stays out of the top-bar direct applications', () => {
    const keys = getDirectApplications(4).map((item) => item.key);
    expect(keys).toEqual(['workbench', 'organization', 'products', 'orders']);
    expect(keys).not.toContain('exam');
  });
});
```
