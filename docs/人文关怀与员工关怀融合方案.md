# 人文关怀与员工关怀融合：改动与兼容

两个产品共用员工关怀后台现有的规则、模板、记录。助手停用自己的 `careRulesStore` 和本地 `CareRule`。后台页面不用改，把现有读写暴露给助手调用即可。

保存用补丁：只提交本次改过的字段，并先过 `validateRuleDraft`。助手没有采集的字段保持原值。助手只保存它能完整映射的四类：生日、节日、天气、工作强度。读到其余场景时不提供保存。

---

## 1. 要改的地方

| 位置 | 改什么 |
| --- | --- |
| 助手规则存储 | 列表、详情、新建、修改、启停、删除改为调用后台同一套规则读写 |
| 助手统计 | 去掉按全年比例折算的演示数，发送量、积分、覆盖改为按关怀记录汇总 |
| 助手文案 | 规则上的一段 `template` 文案改为写入模板的标题、副标题、祝福语；规则只留 `templateKeys` |
| 后台模板 | 增加可选天气场景字段，取值与规则的 `weatherScenes` 相同。一个启用场景对应一条模板，规则用 `templateKeys` 关联 |

后台规则模型、规则表单、概览页面不用改。校验继续用 `validateRuleDraft`。

---

## 2. 场景与字段如何对齐

助手四类对应后台场景：

| 助手 | 后台 |
| --- | --- |
| birthday | 生日关怀 |
| festival | 节日关怀 |
| weather | 天气关怀 |
| workload | 工作强度关怀 |

写入时按下面映射。后台已有、助手这次没改的字段不要带上空值。

| 助手 | 后台 | 兼容要求 |
| --- | --- | --- |
| name | name | 直接对应 |
| enabled | status | 开为「执行中」，关为「未开始」 |
| points | points | 直接对应 |
| audience 全员 | scope=`部门`，scopeValues=`['all']` | 与后台「全部部门」同一写法 |
| audience 部门或员工 | scope、scopeValues | 写入部门 id 或员工 id，不再只存一句展示文案 |
| triggerTime 里的当天或前一天、时刻 | pushOffset、pushTime | 生日、节日拆成这两项，不要存整句文案 |
| festival | occasion | 只能一个节日，且不能与已有规则重复 |
| validDateRange 长期有效 | validity=`永久生效` | 直接对应 |
| validDateRange 本年、自定义起止 | 无对应字段 | 不能写入。这两类规则后台只有永久生效 |
| reached | 不写在规则上 | 用关怀记录汇总 |
| template 文案 | 模板的 employeeTitle、employeeSummary、blessing | 规则上不留这段文案 |

天气场景键：

| 助手 | 后台 |
| --- | --- |
| extremeHeat | 极端高温，阈值写入 highTemperatureThreshold |
| extremeCold | 极端低温，阈值写入 lowTemperatureThreshold |
| coldWave | 寒潮降温，降温幅度和最低温分别写入 coldWaveDropThreshold、coldWaveMinTemperature |
| rainstorm | 暴雨预警，等级写入 rainWarningLevels |
| snowstorm | 暴雪预警，等级写入 snowWarningLevels |
| typhoon | 台风预警，等级写入 typhoonWarningLevels |
| sandstorm | 沙尘预警，等级写入 sandstormWarningLevels |
| haze | 霾/重污染，阈值写入 hazeAqiThreshold |

预警等级 `blue` / `yellow` / `orange` / `red` 写成「蓝色预警」「黄色预警」「橙色预警」「红色预警」。每个启用的天气场景单独一条模板，模板带上对应场景，文案写进该模板。

工作强度：

| 助手 | 后台 |
| --- | --- |
| dailyHours | 单日超时，dailyWorkHoursThreshold |
| clockOut | 下班过晚，lateOffDutyTime |
| weeklyHours | 每周超时，weeklyWorkHoursThreshold；notifySupervisor 写入 weeklyNotifyManager |
| overtimeDays | 连续加班，consecutiveOvertimeDays；notifySupervisor 写入 consecutiveNotifyManager |

工作强度仍是一条规则一段文案，对应一个模板。
