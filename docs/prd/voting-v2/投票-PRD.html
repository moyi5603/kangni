1. 文档说明

  • 文档来源：基于康尼原型 React/TSX 反向分析（html-to-prd），截图取自本地运行页面 http://127.0.0.1:5173
  • 分析范围：现行应用「投票」(voting-v2)。后台：概览、投票管理（列表/新建/编辑/详情含结果与记录、选项管理）。侧栏「投票装修（仅演示）」为原型样式演示，生产不单独做装修。C 端 H5 与 PC：活动首页、选项详情、我的记录。旧应用「投票-废弃」(voting) 不在本文范围。
  • 生成日期：2026-09-04
  • 可信度：界面与交互以源码为准（代码已实现）；数据模型有字段但表单未露出的标 根据页面推测需要；无后端/RBAC 标 待确认
  • 组件命名：一律 页面-模块-组件名称
  • 数据层：活动内存 store（voteV2Store.ts），刷新恢复种子；装修 persist localStorage koni-vote-v2-decoration。无 HTTP 接口。

2. 功能概述与业务背景

产品定位：企业内部评选投票。运营在后台看数据概览、配置活动规则/封面/选项；员工在 H5/PC 浏览、投票、看选项详情与个人记录。投票后台不单独做装修，若有装修需求通过现有微页面装修实现。

目标用户：后台运营/HR；员工端投票人（原型固定演示用户「张悦」）。

核心场景：看概览 KPI → 创建活动并发布 → 维护选项 → 分享 H5 链接/二维码 → 员工投票 → 详情页看结果与导出记录。发现页版面走微页面装修，不在投票应用内交付独立装修。

主要价值：活动配置驱动投票页（后台预览、H5、PC 共用 VoteV2PhonePreview）。

6. 用户流程

后台发布

  1. 进入投票应用默认落在概览；可点 KPI 进投票管理。
  2. 投票管理 → 新增。填基本设置（名称≤50、时间必填且开始<结束、介绍 RichText 按纯文本≤2000）→ 样式（封面必填 jpg/png、主题色、称谓）→ 功能（分组可选、范围、规则）→ 保存并发布。
  3. 新建成功后跳转编辑页；功能设置内「选项管理」卡片出现「去选项管理」。
  4. 选项管理添加选手 → 列表分享把 H5 链接给员工。
  5. 发现页装修：生产走微页面装修，投票后台不单独做装修。原型「投票装修（仅演示）」仅对照样式，拖拽写草稿、保存 toast「已保存，C端首页已更新」。

运营看结果

  1. 活动详情顶栏「去编辑 / 返回」；页签：详情 / 投票结果 / 投票记录（hash 同步）。
  2. 投票结果：按票数排名、占比；同票并列名次。
  3. 投票记录：姓名、部门、时间、内容；导出 CSV（多选按选项分列，选中格填选项名、未选空）。

员工投票（单选）

  1. 打开 H5/PC 发现页（壳标题=装修 pageTitle，默认「投票」）→ Tab「进行中」→ 点整张卡片进首页。
  2. 点选项上投票按钮 → 校验配额/锁定/范围 → 成功弹窗「今日还可投{remaining}{voteUnit}」（无空格）→ 确定关闭。

员工投票（多选）

  1. 首页按钮文案为「选择」；选中后变「取消」且卡片描边；选中态与详情共用 voteV2SelectionStore。
  2. 底栏：已选摘要 + 提示；未达 min 时确认钮 disabled。
  3. 点确认（文案=voteButtonNoun）调 castVoteV2Many：仅当恰好选 1 项才成功并弹窗；选 0 或 ≥2 项 → toast「请选择1项」（UI 仍允许勾到 max）。

状态显示条件

  • 进行中：名称 Input disabled；时间 RangePicker 两端 disabled；参与范围 Radio/Tree disabled；样式整块与分组、规则区仍可改（样式用 styleLocked=readonly，不走 canEditVoteV2Field）。
  • 进行中保存：若改到配额/单多选/样式/分组且该活动已有 cast，弹出 voteV2LiveSaveImpact 确认（标题「确认保存「…」的进行中修改？」；说明不重算票数、按新规则拦截继续投等）→「确认保存」才写入。
  • 已结束：所有控件 disabled；编辑页底栏无保存，仅返回。
  • 详情 view：页头「去编辑」+「返回」；详情 Tab 为只读表单，无底栏保存条。

7.6 H5 发现投票 / 我的记录

壳标题 = 装修 pageTitle（默认「投票」）。默认装修无轮播、无搜索，仅 vote 块。默认 Tab「进行中」。过滤：状态匹配且 canSeeVoteV2；有搜索块时按名称 includes；再 slice(0, latestCount)。空：「暂无活动」。卡片无 CTA 文案：整卡链接进首页；状态用 StatusPill（受 showStatus）；标题/时间受 showTitle/showTime。布局含 large-image / two-col / left-image / left-text / scroll。「我的记录」在状态 Tab 同行。H5 在 titleBar=false 时不渲染区块标题。

壳标题「我的投票记录」（Tab 链文案仍是「我的记录」）。记录来自该用户全部 cast 聚合；卡片带封面；无记录「暂无投票记录」。CTA「查看」回活动首页。

7.7 H5 活动首页与投票

单选：按钮文案=voteButtonNoun（默认「投票」）。点击 castVoteV2。成功经 voteV2CastUiFeedback 打开弹窗。

弹窗标题「投票成功」，正文 今日还可投{remaining}{voteUnit}（无空格，如「今日还可投2票」），确定钮主题色=themeColor。失败 toast：活动未在投票期 / 该选项已锁定 / 不在参与范围内 / 已达投票上限 / 该选项已达可投次数。

选择后按钮变「取消」、卡片红边。选中态走 voteV2SelectionStore（selectionCampaignId）；后台表单预览不传该 prop，用本地 state。底栏确认钮=voteButtonNoun，未达 min disabled。提交 castVoteV2Many：仅 unique.length===1 成功并弹窗、清选中；否则 toast「请选择1项」。首页触顶 max：不增选且无 toast。打开可见首页 incrementVoteV2ViewCount +1；页面设置开「活动数据」时首页统计展示浏览量。

不在范围或活动缺失：壳标题「评选活动」，文案「不在参与范围内」或「活动不存在」。倒计时：未开始对准 startAt，进行中对准 endAt。

7.8 H5 / PC 选项详情

布局：顶栏活动封面（coverUrl）→ 编号/名称/副标题 → 统计「排名 / 票数 / 距上一名」（值如「第1名」「当前128票」「差32票」）→ 选手大图 → 描述 HTML。H5 底栏 CTA；PC 侧栏 CTA。locked 时按钮 disabled。

单选：CTA=voteButtonNoun，点按 castVoteV2，成功弹窗。多选：CTA「选择/取消」，共享 selection store；确认条规则同首页（提交仍仅允许 1 项）。详情触顶 max：不增选且 toast 多选提示。H5：底栏=确认条+CTA，无分享按钮；PC：侧栏 CTA + 确认条，顶栏可分享（禁止分享时隐藏）。

7.9 PC 发现与首页

PC 复用 H5VoteV2List surface=pc：宽屏壳标题=装修 pageTitle；vote 块 titleBar 默认开时用块 title，关时硬编码「发现投票」；「我的记录」在状态 Tab 行右侧。默认无轮播。卡片无 CTA、StatusPill + 整卡跳转。列数跟装修 columnCount。首页/详情分享仅 PC；投票规则与 H5 相同。

13. 验收标准

  • Given 概览 When 点「投票总数」Then 进入投票管理列表；进行中表「详情」进对应活动详情。
  • Given 未开始活动 When 点删除 Then 确认后列表消失；进行中删除按钮禁用且 Tooltip 正确。
  • Given 空新建表且当前在功能 Tab When 保存 Then 切到基本或样式首个报错 Tab；缺封面时切样式并 toast「请上传封面图」。
  • Given 进行中活动 When 改名称 Then 输入框禁用；改每人可投票 Then 可保存。
  • Given 已结束 When 打开 edit Then 无保存按钮；打开详情 Then 仍有「去编辑」（进只读编辑页）。
  • Given 详情 When 切「投票结果」Then hash 含 /results，表含名次/票数/占比。
  • Given 有记录活动 When 切「投票记录」并导出 Then 下载 CSV 且 toast 已导出 N 条；无记录点导出 Then 暂无投票可导出。
  • Given 投票装修拖入搜索并点保存 When toast Then「已保存，C端首页已更新」；打开 H5 发现页 Then 出现搜索框且壳标题=pageTitle。
  • Given 发现页进行中卡片 When 看卡片 Then 无「查看详情/去投票」CTA，有 StatusPill，点整卡进首页。
  • Given 默认装修 When 打开发现页 Then 无轮播；拖入 banner 保存后才有轮播。
  • Given 单选进行中 H5 When 投票 Then 弹窗「今日还可投N票」；再投 Then 已达投票上限。
  • Given 多选 When 勾 2 项提交 Then toast「请选择1项」；勾恰好 1 项且≥min 提交 Then 成功弹窗并清空选中。
  • Given 进行中活动已有票 When 改配额并保存 Then 出现确认保存影响 Modal。
  • Given H5 活动首页 When 看顶栏 Then 无分享按钮；PC 有分享（非禁止模式）。
  • Given 可见活动首页 When 首次进入 Then viewCount +1；不在范围页 Then 不增。
  • Given 按部门活动且用户不在部门 When 打开首页 Then 不在参与范围内。
  • Given PC 选项详情 When 布局 Then CTA 在侧栏且无 H5 底栏。
