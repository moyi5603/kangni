  • 生成日期：2026-09-04（对照当前源码再更新）
  • 产品确认（2026-09-04）：积分发放与扣回——参加活动、评论、发精彩瞬间、活动评分均可获得规则页配置的固定积分；活动积分在活动结束后发放，若该活动开启签到码则须完成扫码才发活动积分。员工自己删除评论或精彩瞬间须扣回对应积分；管理员删除不扣回。原型规则页可配额度，账本发放/扣回尚未落地。

2. 功能概述与业务背景

产品定位：员工兴趣圈运营工具。后台配置圈子、活动、分类、权限规则与首页装修；员工在 H5/PC 按装修布局发现圈子、加入、报名活动、评论与发布精彩瞬间。

为什么做：把散落的团建/兴趣活动收口到可审核、可发布、可签到、可统计的闭环；装修让运营控制 C 端首页模块顺序与样式。

目标用户：平台运营（B 端）；全员员工、圈子负责人与成员（C 端）。当前 C 端固定演示账号 林浅。

核心场景：运营建圈/审圈/发布圈；装修首页；建活动并发布（无活动审核页）；发签到码；员工浏览→加入→报名（含多场次）→签到→发瞬间。

6. 用户流程

员工报名（P0） 入口：H5/PC 首页活动卡报名或进详情 CTA → 若未入组：无场次则 signupAndJoinFree；有场次则先入组再打开选场 sheet → 已入组：无场次 toggle 报名/取消；有场次打开 sheet 勾选 → toast「报名成功,已通知发起人」或「报名场次已更新」。异常：入组待审则 toast 并禁用 CTA。

员工建圈（P1） 规则允许 → 快捷菜单「创建兴趣圈」→ 名称必填 → 创建。员工创建默认 publishStatus=未发布。需审 toast「已提交审核，通过并发布后对其他员工可见」；无需审 toast「兴趣圈已创建，发布后对其他员工可见」。发现列表还要求已发布。

运营审圈并发布（P0） 列表「审核」→ 通过/驳回 → 未发布时点「发布」→ C 端可发现。撤销发布后其他员工不可见。

运营装修首页（P0） 兴趣圈装修 → 拖选区块/改样式（即时写入 draft）→ 点「保存」把 draft 复制到 published 并 toast「已保存，C端首页已更新」。原型 C 端 useIgDecoration 读的是 draft，故未点保存首页也会变。

运营发活动（P0） 新建活动填封面/标题≤20/排期/人数 → 保存（默认未发布、auditStatus=无需审核、needAudit=false）→ 列表/详情点「发布」→ C 端可见。无提交审批、无活动审核弹窗。

员工建活动（P1） 有资格（负责人，或规则允许成员）→ 创建活动表单 → 成功则 store 写 publishStatus=已发布 + auditStatus=无需审核，toast「活动已发布」。失败 toast「创建失败」。

员工发瞬间（P1） 活动进行中或已结束且已报名 → 发布瞬间（不限次数）。表单必选所属兴趣圈与该圈下已报名活动。未开始/已终止不可发。

员工评分（P1） 活动已结束 → 详情在简介与评论区之间出「活动评分」→ 已报名未评：选星后点「确认评分」，toast「已评分」，每人一次。未报名只看均分/人数，无确认钮。进行中不展示该块。

积分发放与扣回（P1，产品确认） 员工完成动作 → 按规则页固定额度入账（受每日上限）。活动积分：活动结束后结算；开启签到码则未扫码不发活动积分。员工自己删除评论或精彩瞬间 → 扣回该笔已发积分。管理员在后台删除评论/瞬间 → 内容下线，不扣回员工已得积分。原型无账本、C 端无到账/扣回提示。

14. 验收标准

  • Given 运营新建圈子 When 保存成功 Then 默认未发布，C 端不可见；点发布后可见（且审核非待审/驳回）。
  • Given 员工建圈 When 提交 Then 默认未发布，发现列表不可见，直至运营发布（且审核通过）。
  • Given 已发布圈子 When 撤销发布 Then C 端不再展示。
  • Given 默认装修 When 打开 H5 首页 Then 无轮播、无 AI；有搜索、热门兴趣圈、活动、往期精彩回顾（已结束活动卡）。
  • Given 首页活动卡 When 未报名 Then 文案「立即报名」且不含「报名+入组」。
  • Given 装修画布加入 AI 区块 When 打开 H5 首页 Then 可见 AI 入口并可进入对话（当前跟 draft，不必先点保存）。
  • Given 圈子成员 Tab When 打开 Then 负责人标签为「负责人」且可多人，无「组长」。
  • Given 装修工作台 When 看工具栏 Then 仅「保存」，无「发布」。
  • Given 圈子有进行中活动 When 点删除 Then 按钮禁用。
  • Given 兴趣圈/活动列表 When 点置顶 Then 立刻到置顶区顶部；取消置顶立刻回到自定义区第一位。
  • Given 自定义区非首项 When 点上移 Then 与上一条对调且 toast「已上移」；置顶行无上移下移。
  • Given 成员已入组 When 报名单次活动 Then toast 成功且人数+1；再点取消报名。
  • Given 周期活动 When 点立即报名 Then 出现场次 sheet，确认后「报名场次已更新」。
  • Given 入组 pending When 点报名 Then toast 审核中且 CTA 禁用。
  • Given 负责人 When 退出 Then toast 不能退出。
  • Given 规则不允许员工建圈 When 打开快捷菜单 Then 无「创建兴趣圈」。
  • Given 规则仅负责人建活动 When 普通成员进创建活动 Then 空态说明。
  • Given 合法签到 URL When 打开 Then 「签到成功」或「你已签到过这场」。
  • Given 员工发布瞬间 When 提交 Then 必须已选所属兴趣圈与关联活动；产品不要求后台审核；当前 toast 仍写已提交审核（残留）。
  • Given 已结束活动 When 打开详情 Then 简介与评论区之间有「活动评分」；进行中无此块。
  • Given 已报名未评 When 选星并点确认评分 Then toast「已评分」且不再出现确认钮。
  • Given 规则不允许员工建圈 When 打开规则页 Then 无「员工创建兴趣圈是否需要审核」开关。
  • Given 运营新建活动 When 保存成功 Then 默认未发布；点发布后 C 端可见。
  • Given 员工创建活动 When 校验通过 Then toast「活动已发布」且发布状态为已发布。
  • Given 活动列表 When 打开 Then 无「审核状态」「提交审批」。
  • Given 活动详情报名 Tab When 打开 Then 无通过/驳回/批量审核按钮。
  • Given 后台侧栏 When 打开兴趣圈 Then 固定 6 项，无按角色隐藏菜单。
  • Given H5 首页 When 打开 Then 顶栏有返回、无「回主页」。
  • Given 规则设置 When 打开 Then 见「活动积分（仅演示）」，无积分下限。
  • Given 活动已结束 When 员工已参加且未开签到码 Then 发放活动积分（固定额度）。
  • Given 活动已结束且开启签到码 When 员工未扫码 Then 不发放活动积分；扫码完成后才发。
  • Given 员工评论/评分/发瞬间 When 成功 Then 按规则固定积分入账（受每日上限）。
  • Given 员工自己删除评论或精彩瞬间 When 成功 Then 扣回该条已发积分。
  • Given 管理员删除评论或精彩瞬间 When 成功 Then 内容删除且不扣回员工积分。

15. 风险与待确认问题

  • 无登录/组织权限，C 端永远是「林浅」。后台也无菜单级 RBAC（产品确认）。
  • 积分账本未实现。产品确认口径见 7.8；卡标题「仅演示」与确认口径冲突，见优化 #8。
  • 装修：原型无独立「发布」按钮；C 端跟 draft。上线是否改为「仅 published 生效」待确认。
  • 「审核加入」产品是否还要做：代码半成品（见优化 #1）。
  • 活动审核、报名审核：产品确认不做。模型残留见优化 #10。
  • 精彩瞬间审核：产品确认不做。代码残留见优化 #3。
  • 员工活动保存即发布、后台活动需点发布：产品是否接受双轨 待确认。
  • PC 是否要独立信息架构还是继续 overlay 移动栈 待确认。
