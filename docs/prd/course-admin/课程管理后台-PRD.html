课程管理后台 产品需求文档

1. 文档说明

  • 文档来源：基于康尼管理后台 React/TSX 原型代码反向分析（html-to-prd skill）
  • 分析范围：应用「课程」（application key: training）下管理端页面：概览、课程管理、新增/编辑课程、课程详情（含学习记录/评论管理/设置答题）、课件管理、规则设置
  • 生成日期：2026-08-24
  • 可信度说明：界面结构、字段、按钮交互以源码为准，标记为 代码已实现；无后端/权限体系处标记 待确认 或 根据页面推测需要
  • 待确认事项摘要：真实 API、角色权限、封面/文件实际上传存储、学习详情页、答题与考试题库联动规则边界
  • 输出格式：HTML 图文需求文档（截图目录 screenshots/）
  • 组件命名规则：一律使用 页面-模块-组件名称

2. 产品概述

产品定位：企业员工培训场景下的课程资产管理后台，覆盖课程分类、课程/课件 CRUD、发布状态、评论审核、学习记录查看、课后答题配置与奖励规则。

目标用户：代码中可见创建人示例为「陈产品」；目标角色为培训运营 / 课程管理员。待确认是否与 HR、部门管理员分权。

核心使用场景：

  • 维护课程分类树与课件分类树，管理视频/音频/PDF 课程与课件
  • 配置课程目录（课件组合、学时、必学、排序）与学习过程（不限制 / 按序学习）
  • 发布/下架课程，员工端可见性随之变化（文案已说明）
  • 审核课程评论，配置评论/点赞/收藏开关
  • 为课程配置练习题库抽题规则；配置积分/学分奖励规则

页面/系统主要价值：把培训内容生产、发布、互动审核与激励规则收敛在同一应用内，便于运营闭环。

5. 用户流程

5.1 发布一门课程（主流程）

  1. 入口：课程管理 → 新增课程（或先在课件管理上传课件）
  2. 填写基本信息、学习设置，添加至少一个课件到目录，可选评论配置
  3. 保存 → 状态为「草稿」，返回列表，提示成功
  4. 行操作「发布」或批量发布 → 状态「已发布」，员工端可见（文案说明）

5.2 评论审核

  1. 概览「待审核评论」或详情「评论管理」
  2. 通过：确认弹窗 → 员工端可见；驳回：仅作者可见（文案）
  3. 支持批量通过/驳回/删除（评论管理 Tab）

5.3 异常

  • 已发布课程不可删除：提示先下架
  • 分类下仍有课程：删除分类被拦截
  • 分类超过 3 级：创建失败提示
  • 表单未保存离开：确认弹窗「未保存的修改将丢失」
  • 详情 ID 无效：Empty「课程不存在或已删除」

11. 验收标准

  1. Given 进入课程应用，When 查看侧栏，Then 可见概览/课程管理/课件管理/规则设置。
  2. Given 填写合法课程表单且目录≥1，When 保存，Then 列表出现草稿课程。
  3. Given 草稿课程，When 发布，Then 状态为已发布且不可删除。
  4. Given 待审评论，When 概览通过，Then 待审列表更新且持久化刷新后仍在。
  5. Given 规则启用 duration 模式，When 缺间隔分钟，Then 无法保存。
  6. Given 课件分类下有课件，When 删除该分类，Then 被占用提示阻止。
